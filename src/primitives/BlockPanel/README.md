# BlockPanel

A flat block, surface or accent panel for the one thing a section's reader is working in.

## Use when

- One panel holds live state, such as the call to act.

## Avoid when

- Every section gets one; use plain flow instead.

## Anatomy

Root `section.cieo-p-block-panel` with `data-tone`.

## Behavior

No motion.

## Keyboard / accessibility

- Text uses the tone's partner colour.

## Do / don't

- Do: `<BlockPanel>Call your senators. (202) 224-3121</BlockPanel>`
- Don't: Don't nest panels.

## Apple twin

`CieoUI.BlockPanel` with the same name and rules; see docs/apple-components.md.
