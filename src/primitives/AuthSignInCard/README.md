# AuthSignInCard

Full sign-in card with heading, credentials, routes, and status.

See the component props in `manifest.json`. Headings are `h2`, async results use `role="status"`, errors use `role="alert"`.

Pending labels and status/error presence use Cieo's base token. Structural auth panes use the shared base swap with soft measured height. Reduced motion and `data-motion="off"` update instantly.
