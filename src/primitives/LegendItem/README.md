# LegendItem

A chart key: a square swatch and the meaning in words.

## Use when

- A bar or chart uses colour for groups.

## Avoid when

- There is only one series.

## Anatomy

Root `span.cieo-p-legend-item`.

## Behavior

No motion.

## Keyboard / accessibility

- The words carry the meaning; the swatch is decorative.

## Do / don't

- Do: `<LegendItem color="var(--party-r)">Republican</LegendItem>`
- Don't: Don't use a legend instead of labelling bar ends.

## Apple twin

`CieoUI.LegendItem` with the same name and rules; see docs/apple-components.md.
