Motion Atoms

Every motion pattern the block library and admin primitives need, as live atoms. Each frame is a pure function of time. Springs are closed-form and critically damped, so nothing overshoots. Click, drag, hover and type in any tile. Agent marks, icons and illustrations live on their own page.

  • M · Morph one element changes size, radius and color
  • S · Swap content blurs out, then in, never overlapping
  • D · Drag 1:1 with the pointer, settles from release velocity
  • E · Edges leading edge moves first, trailing edge lags 60ms
  • X · Enter/exit popovers, toasts and sheets arrive and leave
  • T · Time loops and counts computed from the clock
  • Success · Warning · Danger end states, from Studio’s status tokens
