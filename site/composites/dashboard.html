Behavior

  • Section buttons switch Overview, Orders, and Settings panels with the current marker moving. Arrow keys, Home, and End move between sections.
  • Orders can be searched, filtered by status, and sorted from any column header; the count line reports what is shown.
  • Refresh shows a loading state before re-rendering. Clearing the filters restores the list, and the demo can preview and restore the empty state.
  • Settings validate before saving: the store needs a name and a filled reply-to needs an @ sign. Errors flag inline and focus moves to the first one.
  • Settings persist under the cieo-dashboard-settings key and survive reload, including private mode. Discard returns the form to the last saved values.
  • Save confirms visibly; editing again hides the confirmation until the next save.
  • Escape clears the order search. Enter inside a settings field saves.

Related flows

  • Storefront — the buyer side that creates the orders listed here.
  • Chat — talk through store settings with the local demo assistant.
  • Booking — schedule the visits tied to these orders.
