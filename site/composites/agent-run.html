Behavior

  • The page replays a fixed event log into a real agent store, one event at a time. The screen renders only what the store holds.
  • The run pauses on an approval. Approve or Deny disables both buttons while the decision is sent, and the request keeps saying it is waiting until the log reports the decision.
  • Stop shows only while the run is live. While the stop is sent, the status stays what the log last said.
  • Streamed text is set as plain text, never as HTML. The message is busy until the log completes it.
  • Replay starts over from an empty store.
