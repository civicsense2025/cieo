Behavior

  • Every step reads with scripts disabled; the stepper only takes over once scripts load.
  • Forward moves validate first — a missing name, a broken email, an unpicked theme, or an unchosen digest each raise their own inline note and hold the step.
  • Skip links jump without validating; skipped answers read as — in the summary.
  • The meter and the stepper track the open step and announce it to assistive tech.
  • Copy uses the async clipboard first and drops to a local select-and-copy fallback; the code never leaves this page.
  • Start over returns to Welcome and restores the defaults.
  • Keyboard path: Tab reaches every control, Enter advances from a text field, Left and Right move across the stepper, Esc steps back one screen.
  • Reduced motion is honored — transitions switch off and focus moves without scrolling.
