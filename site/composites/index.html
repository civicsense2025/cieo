Composites

Whole screens built only from the library's parts. Each one doubles as proof the parts fit together.

  • 01Admin dashboardTrack orders and adjust store settings from one admin screen.
  • 02StorefrontInspect the product, set quantity, and complete checkout in one flow.
  • 03AI chatHold a threaded conversation in a workspace that answers locally.
  • 04Agent runFollow a replayed agent run: streamed text, a tool call, an approval that waits for the log, and a saved draft.
  • 05BookingChoose a day and time, share details, and receive a reference.
  • 06SettingsEdit profile and preferences with validation, search, and save that persists.
  • 07InboxRead threads, reply locally, and archive with undo.
  • 08OnboardingStep through welcome, profile, and preferences to a done state with invite code.

Cieo is spring motion and interface parts for the web and SwiftUI. MIT licensed.
