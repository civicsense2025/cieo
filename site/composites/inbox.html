Keyboard shortcuts

  • Up and Down move through the thread list.
  • Enter opens the focused thread and marks it read.
  • / focuses search; r focuses the reply box; Cmd + Enter sends; Esc returns to the thread list.
  • a archives, d deletes, and u undoes the last move.

Behavior

  • Selecting a thread shows its full message and marks it read; unread counts update on the page.
  • Replies validate: empty sends show a fix-it note and stay put; valid replies append to the open thread only.
  • Archive and delete hide the thread and raise an undo banner; Undo restores it and reselects it.
  • Search narrows senders and subjects locally; no match shows the no-results state, no threads shows the empty-inbox state.
  • Keyboard path: Tab reaches the list, arrows move, Enter opens, / jumps to search, r jumps to reply, Cmd+Enter sends, a archives, d deletes, u undoes, Escape returns to the list.
  • Everything runs locally — replies, moves, and search never leave the page.
