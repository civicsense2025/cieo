SelectableCard

Checkable card for picking one option among visible cards (monthly vs. yearly billing).

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { SelectableCard } from 'cieo/SelectableCard';

Monthly

$12.00 per month, cancel anytime.

<SelectableCard label="Monthly billing" selected onSelect={pickMonthly}>
  <h2>Monthly</h2>
  <p>$12.00 per month, cancel anytime.</p>
</SelectableCard>

Properties

NameTypeDefaultDescription
labelstring—Accessible name for the option. Required.
selectedbooleanfalseWhether the card is selected.
onSelectfunction—Called when the card is toggled.

Best practices

Name each card after its option so the choice reads without vision.
Don't nest links or buttons inside; they break the checkbox contract.
