TableHeaderCell

Table header cell with scope and optional sort button.

Usage

Party
<TableHeaderCell sort="asc" onSort={...}>Name</TableHeaderCell> for a sortable column.

Properties

NameTypeDefaultDescription
scopecol | rowcolHeader scope.
sortnone | asc | descnoneSort state; none renders a plain th, asc/desc renders a sort button.
onSortfunction—Called when the sort button is pressed. Host updates data order.
childrenslot—Header content. Required.

Best practices

Pass sort and onSort for sortable columns so headers announce order.
Don't sort data inside the component; the host owns data order.
