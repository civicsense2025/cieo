ReactionSummary

Chips under a message or comment showing which reactions it has, how many people used each, and whether you are one of them.

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { toggleReaction, reactionName, reactionDiff, ReactionSummary } from 'cieo/ReactionSummary';
const [list, setList] = useState(reactions);
<ReactionSummary
  reactions={list}
  onToggle={(id) => setList(toggleReaction(list, id))}
  onAdd={(id) => setList(toggleReaction(list, id, emoji, label))}
/>

Properties

NameTypeDefaultDescription
reactions{ id: string; emoji: string; label: string; count: number; mine?: boolean }[]—Chips in display order: id, emoji, label, count, mine.
onToggle(id: string) => void—Called with a chip id when pressed.
onAdd(id: string) => void—When given, shows an add-reaction button that opens a picker.
available{ id: string; emoji: string; label: string }[]—Reactions the picker offers.
classNamestring—Appended to the root classes without replacing library classes.
slotPropsobject—Typed presentation record; see TypeScript declaration. Named parts: root, list, slot, chip, emoji, count, add.

Guide

Use when

  • Under a comment, message or post that people react to.
  • You want one tap to add or remove your own reaction.

Avoid when

  • A single like count; use CountButton.

Anatomy

A group of chip buttons (emoji plus a rolling CompactCount), then an optional add button that opens a ReactionPicker in a Popover. toggleReaction(list, id, emoji?, label?) returns the next list.

Behavior

  • The host owns the list. onToggle(id) fires on a chip; onAdd(id) fires from the picker.
  • toggleReaction: turning mine off decrements and removes the chip at 0; turning it on increments, or appends a new chip with count 1 and mine.
  • A newly added chip opens its width on the base spring; a removed chip collapses before it disappears; neighbours slide (FLIP).
  • Mine chips use the accent-soft background.

Keyboard / accessibility

  • Chips are buttons with aria-pressed equal to mine, named like "Love, 3 people including you".
  • The add button is named "Add a reaction"; Escape closes the picker and returns focus to it.

Do / don't

  • Do: update the list optimistically with toggleReaction, then confirm with the server.
  • Don't: re-sort chips on every change; keep order stable.

Customization

Pass available to change what the picker offers.

Limitations

  • Wraps onto several lines on narrow screens.
  • Does not name who reacted; add a Tooltip or sheet in the host for that.

Related

ReactionPicker, CompactCount, Popover, Comment.

Host customization

className appends a root class. slotProps exposes root, list, slot, chip, emoji, count, add. Each part accepts className, style, title, and non-reserved data-* attributes. Existing content props and children remain the composition slots. Library classes are retained; computed inline geometry, state attributes, handlers, refs, roles, and accessibility attributes remain owned by Cieo.

Best practices

Use toggleReaction for the optimistic update, then confirm with the server.
Don't hide your own reaction when the count is 1; keep the chip so it can be undone.
