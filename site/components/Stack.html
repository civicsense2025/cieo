Stack

Vertical rhythm for grouped content: one gap between every child (card internals, rows of fields).

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { Stack } from 'cieo/Stack';

Card title

Card body text.

<Stack gap="md">
  <h2>Card title</h2>
  <p>Card body text.</p>
  <button>Save</button>
</Stack>

Properties

NameTypeDefaultDescription
gapsm | md | lgmdSpace between every child.
classNamestring—Appended to the root classes without replacing library classes.
slotPropsobject—Typed presentation record; see TypeScript declaration. Named parts: root.

Best practices

Use one gap for blocks sharing a card, panel, or row.
Don't use Stack for page grids or multi-column layouts; that is Grid.
