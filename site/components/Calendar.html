Calendar

Month grid for picking one ISO date, with pressed-state days and no grid roles.

Usage

SuMoTuWeThFrSa
<Calendar year={2026} month={10} selected={day} onSelect={setDay} />

Properties

NameTypeDefaultDescription
yearnumber—Full year shown in the grid.
monthnumber—Month of year, 1 to 12.
selectedstring—Selected day as an ISO date.
onSelect(iso: string) => void—Called with the ISO date when a day is picked.

Best practices

Own the selected day in the host and pass month navigation with it.
Don't add grid roles or roving tabindex; the flat button list is the contract.
