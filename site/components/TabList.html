TabList

Tab row that owns the selected value while the host owns the panels.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { TabList, TabContext } from 'cieo/TabList';
import { TabList } from 'cieo';
import { Tab } from 'cieo';
const [tab, setTab] = useState('general');
<TabList label="Settings sections" value={tab} onValueChange={setTab}>
  <Tab value="general">General</Tab>
  <Tab value="billing">Billing</Tab>
  <Tab value="team">Team</Tab>
</TabList>

Properties

NameTypeDefaultDescription
labelstring—Accessible name for the tab row.
valuestring—Selected tab value when controlled.
defaultValuestring—Initial selected value when uncontrolled.
onValueChange(value: string) => void—Called with the newly selected value.
motionbooleantrueFalse renders the end state instantly.

Best practices

Render matching tabpanels in the host and swap them on value change. Indicator slides to the selected tab with a lagging edge; motion=false jumps it instantly.
Do not put tab panels inside the row; the row owns selection only.
