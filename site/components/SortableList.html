SortableList

Controlled drag-and-drop and keyboard reordering for lists and table rows.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { sortableMove, sortableDropIndex, sortableAnnouncement, sortableKeyAction, sortableStep, SortableList, SortableListContext } from 'cieo/SortableList';
  • Draft
  • Review
const [order, setOrder] = useState(['draft', 'review', 'live']);
<SortableList label="Stages" order={order} onReorder={setOrder}>
  <SortableListItem id="draft" label="Draft">Draft</SortableListItem>
  <SortableListItem id="review" label="Review">Review</SortableListItem>
  <SortableListItem id="live" label="Live">Live</SortableListItem>
</SortableList>

Best practices

Keep the order in state and give every item a stable id and a readable label.
Don't use array indexes as ids; identity would change as items move.
