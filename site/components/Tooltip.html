Tooltip

Hover and focus hint for icon-only controls.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { Tooltip } from 'cieo/Tooltip';
Copy link
<Tooltip text="Copy link">
  <button aria-label="Copy link">Copy</button>
</Tooltip>

Properties

NameTypeDefaultDescription
textstring—Hint text in the bubble. Required.
motionbooleantrueFalse renders the end state instantly.
enteringnone | fade | rise | scalefadeEntering behavior.
exitingnone | fade | rise | scalefadeExiting behavior.
classNamestring—Appended to the root classes without replacing library classes.
slotPropsobject—Typed presentation record; see TypeScript declaration. Named parts: trigger, root, bubble.

Best practices

Wrap an icon-only button that keeps its own aria-label.
Don't put a link or button inside the bubble; tooltips are hints, not menus.
