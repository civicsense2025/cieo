AgentActivity

The ordered log of what an agent run did, one row per confirmed event.

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { AgentActivity } from 'cieo/AgentActivity';
  1. Run started
  2. Searched the docs
<AgentActivity entries={activity} describe={(e) => words[e.type] ?? e.type} />

Properties

NameTypeDefaultDescription
entriesreadonly ActivityEntry[]—Activity entries in log order, e.g. from selectActivity.
describe(entry: ActivityEntry) => ReactNode—Turns one entry into the row's content. Keep it short and plain.
labelstringAgent activityAccessible name for the log. Defaults to "Agent activity".
emptyTextstring—Shown as the only row while the log is empty. Optional.
classNamestring—Appended to the root classes without replacing library classes.
slotPropsobject—Typed presentation record; see TypeScript declaration. Named parts: root.

Guide

Use when

  • You show a run's history from selectActivity in cieo/agent.

Avoid when

  • You show the conversation itself; use StreamingMessage and ChatMessageList.
  • You need rows for things the host has not confirmed yet. This log only renders what the store holds.

Anatomy

ol.cieo.cieo-p-agent-activity[role=log][aria-label] with one li[data-type][data-seq] per entry, keyed by sequence. An optional li[data-empty] shows while the log is empty.

Behavior

No motion: a row appears in its final state. Rows follow the store's order, and the store's ring cap bounds the list. describe turns each entry into its content.

Keyboard / accessibility

  • role="log" makes new rows polite announcements. Keep describe output short.
  • label defaults to "Agent activity"; set it when a page has several logs.

Do / don't

  • Do: describe={(e) => words[e.type] ?? e.type}.
  • Don't: put buttons in every row; a log is for reading.

Customization

label, emptyText and the row content. Spacing and dividers come from tokens.

Limitations

  • No virtualization. The store caps activity at 500 entries by default.
  • No grouping by agent; filter entries before passing them.

Related

ToolCallDisclosure, AgentLanes, selectActivity.

Host customization

className appends a root class. slotProps exposes root. Each part accepts className, style, title, and non-reserved data-* attributes. Existing content props and children remain the composition slots. Library classes are retained; computed inline geometry, state attributes, handlers, refs, roles, and accessibility attributes remain owned by Cieo.

Best practices

Do keep each row short and plain.
Don't add rows the host has not confirmed.
