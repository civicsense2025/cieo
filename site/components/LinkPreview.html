LinkPreview

A link card with image, favicon, domain and a two-line title that is one tab stop, with a skeleton that cross-fades to content.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { displayDomain, LinkPreview } from 'cieo/LinkPreview';

<LinkPreview url={card.url} title={card.title} image={card.image} favicon={card.favicon} loading={!card} />

Properties

NameTypeDefaultDescription
urlstring—Address the card opens. Anything but http or https renders a card that is not a link.
titlestring—Page title, clamped to two lines.
siteNamestring—Site name beside the favicon. Defaults to the domain.
descriptionstring—Short summary, shown on the large card only.
image{ src: string; alt: string; width?: number; height?: number }—Lead image: 16:9 on top for large, a square thumbnail for compact.
faviconstring—Small site icon address.
variant'large' | 'compact'largelarge puts the image on top; compact puts a thumbnail on the left.
loadingbooleanfalseTrue shows a skeleton with the same footprint.
classNamestring—Appended to the root classes without replacing library classes.
slotPropsobject—Typed presentation record; see TypeScript declaration. Named parts: titleText, root, media, body, content, site, favicon, siteName, domain, title, description.

Best practices

Fetch metadata on the server and pass loading while it is in flight so the card keeps its size.
Don't render the host page's own markup inside the card; pass fields and let the card escape them.
