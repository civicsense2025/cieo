RadioListItem

One radio option inside a RadioList: a thin contract over the Radio control.

Usage

<RadioList label="Delivery speed">
  <RadioListItem label="Standard" value="standard" />
  <RadioListItem label="Express" value="express" />
</RadioList>

Properties

NameTypeDefaultDescription
labelstring—Visible name of the option.
valuestring—Submitted value when this option is picked.
hideLabelbooleanfalseKeep the label for assistive tech only.
descriptionstring—Extra help text bound via aria-describedby.

Best practices

Give every option a stable value inside its RadioList.
Don't use a radio for multi-select; use CheckboxListItem instead.
