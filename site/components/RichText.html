RichText

Turns plain post text into safe inline links, @mentions, #tags and line breaks without ever injecting HTML.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { trimUrl, tokenizeRichText, shortenUrl, RichText } from 'cieo/RichText';
Source: x.com/joelw
Thanks @joelw for the tip #florida
<RichText text={post.body} hrefFor={{ mention: (h) => `/u/${h}`, tag: (t) => `/tag/${t}` }} />
tokenizeRichText("Source: x.com/joelw") // url token

Properties

NameTypeDefaultDescription
textstring—Plain post text. Rendered as text nodes, never as HTML.
hrefFor{ mention?: (handle: string) => string; tag?: (tag: string) => string }—Address builders for @mentions and #tags.
maxUrlLengthnumber28Longest visible link text before it is ellipsized.

Best practices

Pass the raw text from the author; the tokenizer decides what is a link.
Don't pre-convert text to HTML or use dangerouslySetInnerHTML; only http and https addresses ever become links.
