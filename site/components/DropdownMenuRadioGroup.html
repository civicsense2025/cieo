DropdownMenuRadioGroup

Single-select group of menu radio rows, for one sort order out of several.

Usage

import { DropdownMenuRadioGroup } from 'cieo';
const [order, setOrder] = useState('newest');
<DropdownMenuRadioGroup value={order} onValueChange={setOrder}>
  <DropdownMenuRadioItem label="Newest first" value="newest" />
  <DropdownMenuRadioItem label="Oldest first" value="oldest" />
</DropdownMenuRadioGroup>

Properties

NameTypeDefaultDescription
labelstring—Accessible name when the group needs its own announcement.
valuestring—Picked item value when controlled.
defaultValuestring—Initial picked value when uncontrolled.
onValueChange(value: string) => void—Called with the newly picked value.

Best practices

Keep the group style-free and put all visuals on the rows.
Do not nest groups; one single-pick cluster per menu section.
