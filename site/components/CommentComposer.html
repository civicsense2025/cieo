CommentComposer

Input row for a thread: autosizing text, slots for tools, attachments and a recorder, reply context and a character ring.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { composerLength, composerCanSubmit, composerShowsCount, composerKeyAction, CommentComposer } from 'cieo/CommentComposer';
YO
<CommentComposer value={text} onValueChange={setText} onSubmit={post} avatar={<Avatar name="You" initials="YO" />} tools={<Tools />} maxLength={280} />

Properties

NameTypeDefaultDescription
valuestring—Current text.
onValueChange(value: string) => void—Called on every edit.
onSubmit(value: string) => void—Called with the trimmed text when posting is allowed.
placeholderstringAdd to thread…Hint while empty.

avatarReactNode—Author avatar slot.
toolsReactNode—Icon button slot.
attachmentsReactNode—Previews slot.
hasAttachmentsboolean—Allows posting with empty text.
recorderReactNode—Replaces the text input while present.
replyingTo{ author: string; excerpt: string }—Shows a reply quote above the input.
onCancelReply() => void—Dismiss handler for the reply quote.
maxLengthnumber—Character limit.
submitLabelstringPostPost button text.
pendingboolean—A post is in flight.
disabledboolean—Blocks input and posting.

Best practices

Put a voice recorder in `recorder` and its finished clip in `attachments` with `hasAttachments`.
Don't build your own Cmd/Ctrl+Enter handling; the composer maps it.
