TableSelectionToolbar

Selected-count bar with bulk table actions.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { TableSelectionToolbar } from 'cieo/TableSelectionToolbar';
3 selected
<TableSelectionToolbar selectedCount={3}> with Export and Delete buttons.

Properties

NameTypeDefaultDescription
selectedCountnumber—Number of selected rows. Required.
childrenslot—Bulk action buttons. Required.

Best practices

Pass the host's real selection length as selectedCount.
Don't show the bar when nothing is selected; hide it instead of "0 selected".
