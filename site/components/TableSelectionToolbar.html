TableSelectionToolbar

Selected-count bar with bulk table actions.

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { TableSelectionToolbar } from 'cieo/TableSelectionToolbar';
3 selected
<TableSelectionToolbar selectedCount={3}> with Export and Delete buttons.

Properties

NameTypeDefaultDescription
selectedCountnumber—Number of selected rows. Required.
childrenslot—Bulk action buttons. Required.
classNamestring—Appended to the root classes without replacing library classes.
slotPropsobject—Typed presentation record; see TypeScript declaration. Named parts: root.

Guide

Use when

  • One or more table rows are selected and bulk actions apply.
  • The host can pass an exact selectedCount and action buttons.

Avoid when

  • Nothing is selected; hide the bar instead of showing "0 selected".
  • Actions apply to the whole table; use a plain Toolbar instead.

Anatomy

role="toolbar" named "N selected"; a count label plus host action children (Delete, Export).

Behavior

No motion. Renders the count text and actions; selection state stays with the host.

Keyboard / accessibility

  • Toolbar name always matches the visible count; update both together.
  • Actions keep native button focus and order inside the toolbar.

Do / don't

  • Do: <TableSelectionToolbar selectedCount={3}> with Delete/Export buttons.
  • Don't: invent a count; pass the host's real selection length.

Customization

Count value only. Layout and surface come from Cieo tokens.

Limitations

  • Max 8 actions. More means the bulk workflow needs its own screen.
  • No select-all logic; the host owns selection controls.

Related

Table (organism), TableRow (atom), Toolbar (organism).

Host customization

className appends a root class. slotProps exposes root. Each part accepts className, style, title, and non-reserved data-* attributes. Existing content props and children remain the composition slots. Library classes are retained; computed inline geometry, state attributes, handlers, refs, roles, and accessibility attributes remain owned by Cieo.

Best practices

Pass the host's real selection length as selectedCount.
Don't show the bar when nothing is selected; hide it instead of "0 selected".
