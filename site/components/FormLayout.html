FormLayout

Field grid for forms, one column by default (sign-in, settings, checkout).

Usage

<form aria-label="Contact details">
  <FormLayout columns={2}>
    <label>First name<input name="first" /></label>
    <label>Last name<input name="last" /></label>
  </FormLayout>
</form>

Properties

NameTypeDefaultDescription
columnsinteger1Column count (1-4).

Best practices

Put labelled fields inside a host form with a two-column grid.
Don't render the form tag here; nested forms are invalid HTML.
