FormLayout

Field grid for forms, one column by default (sign-in, settings, checkout).

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { FormLayout } from 'cieo/FormLayout';
<form aria-label="Contact details">
  <FormLayout columns={2}>
    <label>First name<input name="first" /></label>
    <label>Last name<input name="last" /></label>
  </FormLayout>
</form>

Properties

classNamestring—Appended to the root classes without replacing library classes.

Best practices

Put labelled fields inside a host form with a two-column grid.
