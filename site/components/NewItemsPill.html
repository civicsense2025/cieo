NewItemsPill

A pill that drops in from a feed edge when new items arrive, rolls its count as more come, and leaves when there are none.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { newItemsLabel, clampNewItems, newItemsAnnouncement, splitNewItemsLabel, NewItemsPill } from 'cieo/NewItemsPill';
<NewItemsPill count={unseen} onShow={() => { scrollToTop(); clear(); }} />
newItemsLabel(1) // "1 new reply"

Properties

NameTypeDefaultDescription
countnumber—How many items are waiting. The pill shows while this is above zero.
onShow() => void—Called when the pill is pressed.
label(n: number) => stringnewItemsLabelFull text for a count, used as the accessible name.
placement'top' | 'bottom'topWhich edge the pill drops in from.

Best practices

Reveal the items and reset the count in onShow so the pill leaves.
Don't count items the reader has already scrolled past.
