StatusDot

Bare presence dot, named only when labelled.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { StatusDot } from 'cieo/StatusDot';
Online
<StatusDot status="success" /> Online

Properties

NameTypeDefaultDescription
statusdefault | success | warning | danger | infodefaultState shown by the dot.
labelstring—Accessible name; required when no adjacent text names the state.

Best practices

Do keep visible text beside the dot naming the state.
Don't leave a lone dot with no text or label.
