Components · atom

LayoutContent

App frame main landmark, unstyled by design (page body goes here).

Usage

House Bill 42

Status: passed committee 8–3.

<Layout>
  …
  <LayoutContent>
    <h2>House Bill 42</h2>
    <p>Status: passed committee 8–3.</p>
  </LayoutContent>
  …
</Layout>

Properties

NameTypeDefaultDescription
labelstring—Accessible name for the main landmark.

Best practices

Put the page body inside LayoutContent within a Layout frame.
Don't render two mains on one page; one main per page.
