ActivityItem

One notification or activity row: who did what, a quoted snippet and when, with an unread dot and optional actions.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { activityMainTag, ActivityItem } from 'cieo/ActivityItem';
AV♥Ava liked your reply 2hGreat point about the timeline, unread
<ActivityItem actor={{ name: "Ava", avatar: <Avatar name="Ava" initials="AV" /> }} icon={<HeartIcon />} unread href="/c/1">liked your reply</ActivityItem>

Properties

NameTypeDefaultDescription
actor{ name: string; avatar: ReactNode }—Who did it, with an avatar node.
iconReactNode—Badge on the avatar corner naming the kind of event.
tone'neutral' | 'accent' | 'danger' | 'success'neutralColors the icon badge.
previewstring—Quoted snippet of the thing acted on.
timestring—Human time text such as 2h.
dateTimestring—ISO time for the time element.
unreadbooleanfalseShows the dot and stronger text; false fades the dot out.
hrefstring—Makes the whole row a link.
onSelect() => void—Makes the whole row a button when there is no href.

Best practices

Put only short follow-up actions such as Follow back in actions.
Don't nest your own links inside children; the whole row already links.
