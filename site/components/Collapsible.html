Collapsible

Disclosure with internal state and a controlled override.

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { Collapsible } from 'cieo/Collapsible';
<Collapsible title="Meeting filters"> with optional date and ward refinements inside.

Properties

NameTypeDefaultDescription
titlestring—Button label for the disclosure. Required.
openboolean—Controlled open state; omit for internal state.
defaultOpenbooleanfalseInitial open state for internal state.
onOpenChangefunction—Called with the next open state on toggle.
childrenslot—Revealed content. Required.
classNamestring—Appended to the root classes without replacing library classes.
slotPropsobject—Typed presentation record; see TypeScript declaration. Named parts: root.

Guide

Use when

  • Hiding secondary content behind a titled button (details, filters).
  • One panel stands alone; groups use CollapsibleGroup.

Avoid when

  • Content must always be visible; do not bury required facts.
  • Panels coordinate single-open; use CollapsibleGroup with host state.

Anatomy

Button with aria-expanded plus a role="region" shown when open. open overrides internal state; defaultOpen seeds it.

Behavior

No motion. Uncontrolled by default (useState(defaultOpen)); controlled when open is set. Every toggle calls onOpenChange with the next state.

Keyboard / accessibility

  • Button announces expanded/collapsed; title must name the content.
  • Region appears after the button in order; focus stays on the button.

Do / don't

  • Do: <Collapsible title="Filters"> for optional refinements.
  • Don't: nest Collapsibles three deep; flatten the content.

Customization

Title and open state only. Borders and padding come from Cieo tokens.

Limitations

  • Max 16 content nodes. Larger bodies deserve their own section.
  • No accordion logic; the host coordinates exclusivity via CollapsibleGroup.

Related

CollapsibleGroup (molecule), TreeList (molecule).

Host customization

className appends a root class. slotProps exposes root. Each part accepts className, style, title, and non-reserved data-* attributes. Existing content props and children remain the composition slots. Library classes are retained; computed inline geometry, state attributes, handlers, refs, roles, and accessibility attributes remain owned by Cieo.

Best practices

Use a title that names the hidden content ("Meeting filters").
Don't bury required facts behind a disclosure; keep them visible.
