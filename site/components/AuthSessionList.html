AuthSessionList

Device sessions with per-device revoke and a text-marked current session.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { AuthSessionList } from 'cieo/AuthSessionList';

Sessions

  • MacBook ProPortland · Active nowThis device
  • iPhone 15Portland · 2 hours ago
<AuthSessionList id="sessions" sessions={sessions} onRevoke={revoke} />

Properties

NameTypeDefaultDescription
idstring—Binds the list heading.
sessionsarray—Each entry needs id, device, location, lastActive, and optional current.
onRevokefunction—Fires with the session id to revoke.
classNamestring—Appended to the root classes without replacing library classes.
slotPropsobject—Typed presentation record; see TypeScript declaration. Named parts: root, cardTitle, sessions, session, sessionDevice, sessionMeta, sessionCurrent, revoke.

Best practices

Do mark the current session with "This device" text and leave it unrevocable.
Don't name two revoke buttons alike; each names its device.
