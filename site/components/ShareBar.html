ShareBar

Shares of a whole as one bar; draws nothing unless every share is a positive number.

Usage

import { shareFractions, ShareBar } from 'cieo/ShareBar';
<ShareBar label="Yes 73, No 25" segments={[{ value: 73, color: "#1d4ed8" }, { value: 25, color: "#b42318" }]} />
npx cieo add ShareBar
/* Root selector: .cieo-share-bar (named-slots)
   Tokens: --cieo-space-4 */
import Cieo

// Shared Cieo tokens & Motion.snap spring counterpart for ShareBar
ShareBarView()
  .environment(\.cieoTheme, .instrument)

Anatomy

Properties

NameTypeDefaultDescription
segmentsobject[]—{ value: number; color: string; label?: string }[]
labelstring—Required.
classNamestring—Additional root CSS class. Built-in classes remain.
slotPropsobject—Typed presentation parts: root. Accepts className, style, title and non-reserved data attributes; owned semantics and dynamic styles remain.

Guide

Use when

  • A whole splits into parts, such as seats by party.

Avoid when

  • Any share is unknown; the bar draws nothing rather than guess.

Anatomy

Root div.cieo-p-share-bar[role=img].

Behavior

shareFractions returns null for missing, zero, negative or single shares.

Keyboard / accessibility

  • label reads the split in words.

Do / don't

  • Do: <ShareBar label="Yes 73, No 25" segments={...} />
  • Don't: Don't rely on color; pair with LegendItem and labeled ends.

Apple twin
