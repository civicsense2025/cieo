Typeahead

Controlled combobox shell; host owns filtering, open reflects match presence.

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { Typeahead } from 'cieo/Typeahead';
H.R. 12
<Typeahead label="Find a bill" value={text} onChange={setText} open={matches.length > 0}>
  {matches.map(m => <TypeaheadItem key={m.id} value={m.id} onSelect={pick}>{m.title}</TypeaheadItem>)}
</Typeahead>

Properties

NameTypeDefaultDescription
labelstring—Visible label naming the field.
valuestring—Current text.
onChangefunction—Host text hook.
openbooleanfalseWhether the match list shows.
classNamestring—Appended to the root classes without replacing library classes.
slotPropsobject—Typed presentation record; see TypeScript declaration. Named parts: root, input, list.

Guide

Use when

  • A text field narrows a short match list as the user types.
  • Matches are host data (search results, directory names).

Avoid when

  • The menu is command-first with groups and footers; use CommandPalette instead.
  • Options are static and few; use Selector instead.

Anatomy

<label> plus combobox <input> plus a conditional role="listbox" of TypeaheadItems.

Behavior

No motion. open reflects host match presence; value/onChange carry text. Filtering stays host-side.

Keyboard / accessibility

  • Input carries role="combobox", aria-expanded, and aria-controls; label is required and bound.
  • Item commit is host-owned; keep one tab stop (the input) per field.

Do / don't

  • Do: <Typeahead label="Find a bill" open={matches.length > 0}> with item children.
  • Don't: open with zero matches; close the list instead.

Customization

Field paint only. Borders and list shadow come from Cieo tokens.

Limitations

  • No active-descendant management; host owns highlight and commit.
  • No debounce or fetch; the host supplies matches.

Related

TypeaheadItem (atom), CommandPalette (molecule), Selector (atom).

Host customization

className appends a root class. slotProps exposes root, input, list. Each part accepts className, style, title, and non-reserved data-* attributes. Existing content props and children remain the composition slots. Library classes are retained; computed inline geometry, state attributes, handlers, refs, roles, and accessibility attributes remain owned by Cieo.

Best practices

Derive open from match presence so an empty list never shows.
Don't filter inside the shell; the host owns matches.
