Typeahead

Controlled combobox shell; host owns filtering, open reflects match presence.

Usage

H.R. 12
<Typeahead label="Find a bill" value={text} onChange={setText} open={matches.length > 0}>
  {matches.map(m => <TypeaheadItem key={m.id} value={m.id} onSelect={pick}>{m.title}</TypeaheadItem>)}
</Typeahead>

Properties

NameTypeDefaultDescription
labelstring—Visible label naming the field.
valuestring—Current text.
onChangefunction—Host text hook.
openbooleanfalseWhether the match list shows.

Best practices

Derive open from match presence so an empty list never shows.
Don't filter inside the shell; the host owns matches.
