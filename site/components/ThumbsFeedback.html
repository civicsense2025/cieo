ThumbsFeedback

A "Was this helpful?" prompt that can open a short detail step with reasons and a comment, then thanks the person.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { thumbsStep, ThumbsFeedback, THUMBS_INITIAL } from 'cieo/ThumbsFeedback';

Was this helpful?

<ThumbsFeedback
  reasons={{ up: ["Clear", "Complete"], down: ["Confusing", "Out of date"] }}
  onSubmit={(result) => send(result)}
/>

Properties

NameTypeDefaultDescription
questionstringWas this helpful?The question.
onRate(value: 'up' | 'down') => void—Called as soon as a thumb is pressed.
reasons{ up: string[]; down: string[] }—Reason chips for each thumb; leave a list empty to skip detail.
onSubmit(result: { value; reasons; comment }) => void—Called once with value, reasons and comment.
thanksstringThanks for the feedback.Thank-you text.

Best practices

Ask for reasons only after the thumb; the first tap should cost one click.
Don't make the comment required.
