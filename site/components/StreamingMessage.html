StreamingMessage

An agent message that may still be arriving, rendered as plain text.

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { StreamingMessage } from 'cieo/StreamingMessage';
Researcher9:41

Reading the pricing page. Three plans so far

<StreamingMessage message={message} author="Researcher" />

Properties

NameTypeDefaultDescription
messageMessageView—The message as the store folded it.
authorstring—Author name, e.g. "Researcher". Optional.
timestring—Display time, e.g. "9:41 AM". Optional.
truncatedTextstringTruncatedNote shown when the text was capped. Defaults to "Truncated".
classNamestring—Appended to the root classes without replacing library classes.
slotPropsobject—Typed presentation record; see TypeScript declaration. Named parts: root.

Guide

Use when

  • You show MessageView text from cieo/agent while deltas stream in.

Avoid when

  • The text is trusted Markdown you want formatted; render it with Markdown once complete.

Anatomy

ChatMessage (author, time) → div.cieo.cieo-p-streaming-message[data-complete] → p[data-text] and, when capped, p[data-truncated].

Behavior

Text is plain text with line breaks kept (white-space: pre-wrap). It is never parsed as HTML. aria-busy is set until the message is complete. No motion.

Keyboard / accessibility

  • aria-busy asks assistive tech to wait for the final text.
  • The truncated note is visible text, not only a style.

Do / don't

  • Do: pass the store's MessageView as-is.
  • Don't: inject the text with dangerouslySetInnerHTML.

Customization

author, time, truncatedText. Type and colour from tokens.

Limitations

  • No Markdown or code highlighting.
  • No typing indicator; the host's status words cover that.

Related

ChatMessage, ChatMessageList, AgentLanes.

Host customization

className appends a root class. slotProps exposes root. Each part accepts className, style, title, and non-reserved data-* attributes. Existing content props and children remain the composition slots. Library classes are retained; computed inline geometry, state attributes, handlers, refs, roles, and accessibility attributes remain owned by Cieo.

Best practices

Do pass the store message as-is.
Don't inject the text as HTML.
