StreamingMessage

An agent message that may still be arriving, rendered as plain text.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { StreamingMessage } from 'cieo/StreamingMessage';
Researcher9:41

Reading the pricing page. Three plans so far

<StreamingMessage message={message} author="Researcher" />

Properties

NameTypeDefaultDescription
messageMessageView—The message as the store folded it.
authorstring—Author name, e.g. "Researcher". Optional.
timestring—Display time, e.g. "9:41 AM". Optional.
truncatedTextstringTruncatedNote shown when the text was capped. Defaults to "Truncated".
classNamestring—Appended to the root classes without replacing library classes.
slotPropsobject—Typed presentation record; see TypeScript declaration. Named parts: root.

Best practices

Do pass the store message as-is.
Don't inject the text as HTML.
