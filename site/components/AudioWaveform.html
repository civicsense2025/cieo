AudioWaveform

Bars drawn from a clip's peaks with a continuously filling played portion; a scrubber when onSeek is given.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { waveformBars, seekFromPointer, waveformKeyStep, audioSeekText, useScrub, AudioWaveform, WAVEFORM_FLOOR, WAVEFORM_KEY_SECONDS, MAX_WAVEFORM_BARS } from 'cieo/AudioWaveform';
<AudioWaveform peaks={peaks} duration={63} current={t} onSeek={seek} label="Seek in Voice note" />
waveformBars(peaks, 48)

Properties

NameTypeDefaultDescription
peaksnumber[]—Loudness samples, any length.
durationnumber—Clip length in seconds.
currentnumber—Playhead in seconds.
onSeek(seconds: number) => void—Makes it a slider; omit for a read-only picture.
labelstring—What the waveform is.
barsnumber48How many bars to draw.
classNamestring—Additional root CSS class. Built-in classes remain.
slotPropsobject—Typed presentation parts: root, bars, bar. Accepts className, style, title and non-reserved data attributes; owned semantics and dynamic styles remain.

Best practices

Pass the host's current time and seek handler; the fill glides between updates.
Don't resample peaks yourself; waveformBars buckets by max and keeps a floor.
