NotifyToggle

A bell toggle for new-reply notifications that rings once and pops a check when turned on.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { bellWiggleAngle, bellWiggleFrames, NotifyToggle, BELL_WIGGLE_MS, BELL_WIGGLE_DEGREES } from 'cieo/NotifyToggle';
<NotifyToggle on={on} onToggle={toggle} />

Best practices

Keep the label a plain request such as Notify me about new replies.
Don't ring the bell on load; it rings only when the viewer turns it on.
