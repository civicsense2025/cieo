AspectRatio

Ratio box for media that keeps its shape (video embeds, image frames).

Usage

<AspectRatio ratio="16/9">
  <img src="hearing.jpg" alt="Committee hearing room" />
</AspectRatio>

Properties

NameTypeDefaultDescription
ratiostring—Box ratio as CSS, e.g. 16/9. Required.

Best practices

Hold a 16/9 box around a video embed to avoid layout shift.
Don't put flowing text in the box; fixed ratios clip it.
