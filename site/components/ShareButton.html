ShareButton

Opens the device share sheet or copies the link, then confirms with Link copied.

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { shareMethod, isShareableUrl, runShare, ShareButton, SHARE_COPIED_MS } from 'cieo/ShareButton';
<ShareButton url="https://example.com/p/1" onShared={(m) => track(m)} />

Properties

NameTypeDefaultDescription
urlstring—Absolute http(s) URL to share.
titlestring—Title for the native sheet.
textstring—Text for the native sheet.
labelstringShareVisible label.
onShared(method: 'native' | 'copy') => void—Called after a successful share.
classNamestring—Additional root CSS class. Built-in classes remain.
slotPropsobject—Typed presentation parts: root, button, icon. Accepts className, style, title and non-reserved data attributes; owned semantics and dynamic styles remain.

Guide

Use when

  • Sharing a post or comment link.

Avoid when

  • Sharing a non-web URL; only http and https are shared.

Anatomy

A button with an icon and swapping label, plus a polite live region.

Behavior

  • shareMethod(navigator) picks native, copy or none.
  • After copying, the label reads Link copied for 2 seconds and the live region says it.
  • Cancelling the native sheet is silent. Any other native failure falls back to copying.
  • onShared runs only after a success.

Keyboard / accessibility

A real button; the live region announces the copy and failures politely. Disabled for unsafe URLs.

Do / don't

  • Do: pass a full https URL.
  • Don't: treat a cancel as an error.

Customization

Use the typed presentation parts listed under Host customization. Defaults still use Cieo tokens; component behavior and accessibility remain owned by Cieo.

Limitations

  • Copying needs a secure context and user gesture.

Related

ActionBar, CountButton.

Host customization

className adds a root class without replacing Cieo’s classes. slotProps exposes root, button, icon. Each part accepts className, style, title, and non-reserved data-* attributes. Roles, accessible names, values, event handlers, refs, state markers, and dynamic geometry remain component-owned. Existing content props retain their original semantics.

Best practices

Pass a full https URL; other schemes disable the button.
Don't treat a cancelled share sheet as an error; it is silent.
