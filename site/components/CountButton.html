CountButton

A ghost icon button with a rolling count: a toggle (like, repost) when pressed is given, a plain action (reply) otherwise.

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { countButtonLabel, CountButton, COUNT_BUTTON_DIP } from 'cieo/CountButton';
preset base · ω 22 rad/s · ζ 1.00 · settle 418 ms (1×) · 0.0% overshoot

Guide

Use when

  • Under a post: like, reply, repost.
  • A single action with a count that changes while people watch.

Avoid when

  • The control is only a link to another page; use a link.
  • No count and no toggle; use IconButton.

Anatomy

A button holding an icon (with an optional active icon layered over it) and a CompactCount.

Behavior

  • Accessible name is countButtonLabel(label, count, unit): "Like, 164 likes". Zero or missing count gives just the label.
  • The visible count is shortened and rolls; the exact number lives in the name.
  • On press the icon dips to 80% and settles back on the snap spring; the active icon and tone fade in. Reduced motion has no dip.
  • tone colors hover and pressed states. The host flips pressed.

Keyboard / accessibility

A real button. aria-pressed only when pressed is defined. Visible focus ring; hit target grows to the touch target on coarse pointers.

Do / don't

  • Do: give a verb label ("Like") and the exact count.
  • Don't: add the count to the label yourself.

Customization

Use the typed presentation parts listed under Host customization. Defaults still use Cieo tokens; component behavior and accessibility remain owned by Cieo.

Limitations

  • The icon is host supplied and must be decorative.

Related

ActionBar, CompactCount, IconButton, ToggleButton.

Host customization

className adds a root class without replacing Cieo’s classes. slotProps exposes root, icon, glyph, count. Each part accepts className, style, title, and non-reserved data-* attributes. Roles, accessible names, values, event handlers, refs, state markers, and dynamic geometry remain component-owned. Existing content props retain their original semantics.

Best practices

Give a verb label and the exact count; the visible number is shortened for you.
Don't put the count in the label yourself; it is added so screen readers hear 164, not 164 likes twice.
