CountButton

A ghost icon button with a rolling count: a toggle (like, repost) when pressed is given, a plain action (reply) otherwise.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { countButtonLabel, CountButton, COUNT_BUTTON_DIP } from 'cieo/CountButton';
<CountButton icon={<Heart/>} activeIcon={<HeartFilled/>} label="Like" count={164} countUnit="likes" pressed={liked} onPress={toggleLike} tone="danger" />

Properties

NameTypeDefaultDescription
iconReactNode—Icon for the off state.
activeIconReactNode—Icon that fades in while pressed.
labelstring—Verb that names the button; joined with the exact count.
countnumber—Exact count; zero or missing shows no number.
countUnitstring—Word read after the count, such as likes.
pressedboolean—Defining it makes the button a toggle (aria-pressed).
onPress() => void—Called on every press.
toneCountButtonToneneutralColor of the pressed and hover states.
size'sm' | 'md'mdControl height.
disabledboolean—Disables the button.

Best practices

Give a verb label and the exact count; the visible number is shortened for you.
Don't put the count in the label yourself; it is added so screen readers hear 164, not 164 likes twice.
