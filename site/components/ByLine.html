ByLine

One-line author header: name, badge, context crumb and relative time, with the name giving way before the time does.

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { ByLine } from 'cieo/ByLine';
ginandtanic◎›midterms 2026·1d
<ByLine author="ginandtanic" badge={<VerifiedMark />} context="midterms 2026" time="1d" dateTime="2026-10-22" />

Properties

NameTypeDefaultDescription
authorstring—Display name. Truncates before the time does.
hrefstring—Profile link; only http(s) and relative links become anchors.
badgeReactNode—Slot after the name, such as a verified badge.
contextReactNode—Slot for where the post lives; shown after a separator.
contextHrefstring—Link for the context crumb, same safe-link rule.
timestring—Display text for the age, such as 1d.
dateTimestring—ISO date written to the time element.
handlestring—Account handle without the at sign.
idstring—Id on the root so a parent can label itself by this line.
classNamestring—Additional root CSS class. Built-in classes remain.
slotPropsobject—Typed presentation parts: root, badge, handle, separator, time. Accepts className, style, title and non-reserved data attributes; owned semantics and dynamic styles remain.

Guide

Use when

  • A comment, post or message header.
  • Any list row that needs who, where and when in one line.

Avoid when

  • The header needs several lines or actions; compose your own.

Anatomy

A span holding the author (link or text), optional badge, optional @handle, a › separator and context crumb, and a · separator and time element.

Behavior

  • Flex line with no wrapping: author and context shrink with an ellipsis, badge, separators and time never shrink.
  • safeHref allows http(s) and relative links only; javascript:, data:, protocol-relative and other schemes render as plain text.
  • Separators are aria-hidden; screen readers hear author, badge, context, then the time text.

Keyboard / accessibility

Links are real anchors with a visible focus ring. Give the badge its own accessible name (for example "Verified").

Do / don't

  • Do: keep the context crumb short.
  • Do not: put actions inside the line.

Customization

Use the typed presentation parts listed under Host customization. Defaults still use Cieo tokens; component behavior and accessibility remain owned by Cieo.

Limitations

  • No built-in relative-time formatting; the host supplies the text.

Related

Comment, Avatar, Badge.

Host customization

className adds a root class without replacing Cieo’s classes. slotProps exposes root, badge, handle, separator, time. Each part accepts className, style, title, and non-reserved data-* attributes. Roles, accessible names, values, event handlers, refs, state markers, and dynamic geometry remain component-owned. Existing content props retain their original semantics.

Best practices

Pass short display text for the time and a real ISO date for dateTime.
Don't pass a user-supplied URL through anything but href; unsafe schemes are dropped on purpose.
