AvatarGroup

Static overlapping face stack for rows. Decorative; the row owns the accessible name.

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { AvatarGroup } from 'cieo/AvatarGroup';

Anatomy

Properties

NameTypeDefaultDescription

maxinteger4Faces shown before collapsing into +N.
sizesm | mdmdFace size across the stack.
stylerecord—CSSProperties passthrough; Cieo tokens only, no motion.
labelstring—Optional text after the faces, e.g. 3k love for review counts.
classNamestring—Appended to the root classes without replacing library classes.
slotPropsobject—Typed presentation record; see TypeScript declaration. Named parts: root, avatarStack, avatar, avatarInitials, label.

Guide

Use when

  • A story, event, timeline, vote, or bill row needs "who" at a glance: up to 4 faces plus +N.

Avoid when

  • You need hover fan-out or name popovers in a list. That demo is AvatarGroupAnimated on the catalogue page only; it costs too much across dozens of rows and breaks reduced-motion.
  • A face has no approved photo: render initials, never a guessed photo. Earl Warren shows EW.

Accessibility

  • Stack root is aria-hidden="true". Put names in the row: <li aria-label="Brown v. Board, Warren, Marshall, +2 more">.
  • Never render one name twice (once visible on hover, once hidden). There is no hover text here.

Customization

Size sm|md and max only. Overlap, ring, and initials styling come from tokens.

Limitations

  • Decorative only; it never carries the accessible name itself.
  • Photos must be pre-approved URLs; no fetching, no guessing, no wrong-photo fallback.

Related

Avatar (atom, single face), AvatarGroupAnimated (catalogue demo only), List (organism rows).

Host customization

className appends a root class. slotProps exposes root, avatarStack, avatar, avatarInitials, label. Each part accepts className, style, title, and non-reserved data-* attributes. Existing content props and children remain the composition slots. Library classes are retained; computed inline geometry, state attributes, handlers, refs, roles, and accessibility attributes remain owned by Cieo.

Best practices

Do put the names in the row's aria-label since the stack is hidden.
Don't guess photos; render initials when no approved photo exists.
