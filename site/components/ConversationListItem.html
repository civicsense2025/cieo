ConversationListItem

One row of the inbox: avatar, title and time, preview and unread badge, with typing, draft, muted and pinned states.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { nodeText, unreadBadgeText, conversationLabel, ConversationListItem } from 'cieo/ConversationListItem';
<ConversationListItem id="design" title="Design team" avatar={<GroupAvatar people={members} />}
  preview="Ava: see you at 3" time="9:41 AM" unread={3} onSelect={open} />

Properties

NameTypeDefaultDescription
idstring—Stable id of the conversation.
titlestring—Conversation name.
avatarReactNode—Face of the conversation: an Avatar or a GroupAvatar.
previewReactNode—Last message, cut to one line.
timestring—Short time text for the last message.
dateTimestring—Machine-readable time (ISO 8601).
unreadnumber—Unread messages. Zero hides the badge.
mutedboolean—Notifications are off: muted-bell icon and a neutral badge.
pinnedboolean—Pinned: shows a pin when there is no badge.
draftboolean—The preview is an unsent draft.
typingstring[]—People typing now; replaces the preview.
selectedboolean—This is the open conversation.
hrefstring—Makes the row a link.
onSelect(id: string) => void—Called with the id when the row is activated.
classNamestring—Appended to the root classes without replacing library classes.
slotPropsobject—Typed presentation record; see TypeScript declaration. Named parts: avatar, main, top, title, time, bottom, line, preview, draft, typing, flags, icon, badge, root.

Best practices

Pass the last message as the preview and let the row build its spoken summary from it.
Don't put buttons inside the row; the whole row is the one control.
