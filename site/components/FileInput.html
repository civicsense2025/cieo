FileInput

Labelled file picker: one native file input reusing the shared input style.

Usage

<FileInput label="Upload report" accept=".pdf,.docx" />

Properties

NameTypeDefaultDescription
labelstring—Visible label for the picker.
namestring—Form field name.
acceptstring—Accepted MIME types or extensions.
multiplebooleanfalseAllow multiple files.

Best practices

Constrain the dialog with accept when only some types make sense.
Don't expect drag-and-drop or progress; that is a dropzone, not a FileInput.
