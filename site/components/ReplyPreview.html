ReplyPreview

A quoted reply with an accent bar and a clamped excerpt, dismissible above a composer or tappable inside a message.

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { replyDismissLabel, replyJumpLabel, ReplyPreview } from 'cieo/ReplyPreview';
AvaAgreed, the early vote is the story.
AvaAgreed, the early vote is the story.
<ReplyPreview variant="composer" author="Ava" excerpt="Agreed, the early vote is the story." onDismiss={cancel} />

Properties

NameTypeDefaultDescription
authorstring—Name of the person being replied to.
excerptstring—Short excerpt of the original text.
variant"composer" | "quote"quoteComposer variant can be dismissed; quote variant can jump to the original.
onDismiss() => void—Composer variant: dismiss button handler.
onJump() => void—Quote variant: makes the quote a button that jumps to the original.
classNamestring—Additional root CSS class. Built-in classes remain.
slotPropsobject—Typed presentation parts: bar, text, author, excerpt, root, dismiss. Accepts className, style, title and non-reserved data attributes; owned semantics and dynamic styles remain.

Guide

Use when

  • Above a composer while replying to a specific comment.
  • Inside a bubble or comment that answers another one.

Avoid when

  • Quoting long passages; link to the original instead.

Anatomy

A root (div, or button for a jumpable quote) with an accent bar, the author name, the excerpt, and in the composer variant a dismiss button.

Behavior

  • Excerpt clamps to two lines (one line in the composer variant).
  • Composer dismiss is named "Cancel reply to {author}"; quote jump is named "Go to the message from {author}".
  • Without onDismiss or onJump the matching button is not rendered.

Keyboard / accessibility

Both controls are real buttons with names and focus rings; touch targets grow to the touch size on coarse pointers.

Do / don't

  • Do: pair the composer variant with Escape handling in the input (CommentComposer does).
  • Do not: nest it inside another button.

Customization

Use the typed presentation parts listed under Host customization. Defaults still use Cieo tokens; component behavior and accessibility remain owned by Cieo.

Limitations

  • Plain text excerpts only.

Related

CommentComposer, Comment, ChatMessageBubble.

Host customization

className adds a root class without replacing Cieo’s classes. slotProps exposes bar, text, author, excerpt, root, dismiss. Each part accepts className, style, title, and non-reserved data-* attributes. Roles, accessible names, values, event handlers, refs, state markers, and dynamic geometry remain component-owned. Existing content props retain their original semantics.

Best practices

Keep the excerpt to one or two sentences; the clamp is a safety net.
Don't render a quote variant without onJump if it looks tappable to the reader; it stays plain text without the handler.
