ReplyPreview

A quoted reply with an accent bar and a clamped excerpt, dismissible above a composer or tappable inside a message.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { replyDismissLabel, replyJumpLabel, ReplyPreview } from 'cieo/ReplyPreview';
AvaAgreed, the early vote is the story.
AvaAgreed, the early vote is the story.
<ReplyPreview variant="composer" author="Ava" excerpt="Agreed, the early vote is the story." onDismiss={cancel} />

Properties

NameTypeDefaultDescription
authorstring—Name of the person being replied to.
excerptstring—Short excerpt of the original text.
variant"composer" | "quote"quoteComposer variant can be dismissed; quote variant can jump to the original.
onDismiss() => void—Composer variant: dismiss button handler.
onJump() => void—Quote variant: makes the quote a button that jumps to the original.

Best practices

Keep the excerpt to one or two sentences; the clamp is a safety net.
Don't render a quote variant without onJump if it looks tappable to the reader; it stays plain text without the handler.
