CommentThread

Tree manager for comments: nested lists, a depth cap, per-branch "view more replies" with a reveal animation, rendering every comment through the host.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

Best practices

Build the tree with `buildCommentTree` so orphans and cycles are handled for you.
Don't render nested lists yourself; the thread owns list semantics and the reveal.
