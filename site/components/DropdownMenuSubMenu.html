DropdownMenuSubMenu

Nested flyout menu for one level of overflow, like export formats under Export.

Usage

import { DropdownMenuSubMenu } from 'cieo';
<DropdownMenuSubMenu label="Export as">
  <DropdownMenuItem label="Export PDF" onSelect={exportPdf} />
  <DropdownMenuItem label="Export CSV" onSelect={exportCsv} />
</DropdownMenuSubMenu>

Properties

NameTypeDefaultDescription
labelstring—Accessible name for the nested menu.

Best practices

Keep one nesting level and two to six rows so the flyout stays scannable.
Do not hide the only path to an action in a hover-only flyout on touch layouts.
