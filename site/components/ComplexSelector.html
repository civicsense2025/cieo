ComplexSelector

Label plus a native select grouped into optgroups.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { ComplexSelector } from 'cieo/ComplexSelector';
<ComplexSelector label="District" sections={[
  { label: "House", options: [{ value: "h12", label: "District 12" }] },
  { label: "Senate", options: [{ value: "s4", label: "District 4" }] },
]} />

Properties

NameTypeDefaultDescription
labelstring—Visible label naming the field.
sectionsarray—Grouped sections rendered as optgroups.

Best practices

Pass sections with stable values the server already understands.
Don't use for flat lists; Selector is simpler without groups.
