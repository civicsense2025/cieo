Poll

A question with options that become result bars in place once the person votes or the poll closes.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { pollPercentages, pollAnnouncement, Poll } from 'cieo/Poll';

Which should we ship first?

Option AYour vote54%54%, 54 votes
Option B46%46%, 46 votes

100100 votes votes

Closes Friday

<Poll
  question="Which should we ship first?"
  options={options}
  voted={myVote}
  onVote={(id) => cast(id)}
/>

Properties

NameTypeDefaultDescription
questionstring—The question and group name.
options{ id: string; label: string; votes: number }[]—Options with id, label and vote count.
votedstring | null—Id the person chose; null if they have not voted.
onVote(id: string) => void—Called with the option id when the person votes.
closedbooleanfalseTrue once voting is over; results show without a vote.
footnoteReactNode—Extra line under the total.

Best practices

Show the total so a 100% bar from one vote is not misread.
Don't hide results behind a second click after voting.
