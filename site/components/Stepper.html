Stepper

Progress steps rendered from an array; pure render.

Usage

  1. Account
  2. Payment
  3. Review
<Stepper label="Signup progress" steps={[{ label: "Account", state: "done" }, { label: "Payment", state: "current" }, { label: "Review", state: "todo" }]} />

Properties

NameTypeDefaultDescription
labelstring—Accessible name for the progress nav.
stepsarray ({label, state})—Steps in order; exactly one should be current.

Best practices

Keep exactly one step current and let the host advance state.
Don't use a linear stepper for a branching flow.
