Pagination

Windowed page nav (±2 around the current page).

Usage

<Pagination page={3} pageCount={12} onPageChange={setPage} />

Properties

NameTypeDefaultDescription
pageinteger—Current page (1-based).
pageCountinteger—Total page count.
onPageChangefunction—Page change handler.
labelstringPaginationAccessible name.

Best practices

Keep page state in the host and clamp it to 1..pageCount.
Don't reset the page silently when the list changes.
