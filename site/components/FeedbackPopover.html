FeedbackPopover

A small non-modal comment box with an optional thread above it, placed beside a point and flipped to stay inside its container.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { placePopover, isSubmitShortcut, commentText, FeedbackPopover } from 'cieo/FeedbackPopover';

Comment 3

Ava: Can this heading be larger?

<FeedbackPopover open={open} onOpenChange={setOpen} onSubmit={addComment} title="Comment 3">
  <p>Ava: Can this heading be larger?</p>
</FeedbackPopover>
placePopover({ x: 100, y: 200 }, { width: 280, height: 160 }, { width: 800, height: 600 })

Best practices

Show the existing thread above the box so replies keep their context.
Don't use it for decisions that must block the page; it is not modal.
