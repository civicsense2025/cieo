AudioLevelMeter

Bars that rise and fall with how loud the microphone is, driven by a level you pass or a stream the meter listens to itself.

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { rmsLevel, levelBars, AudioLevelMeter } from 'cieo/AudioLevelMeter';
<AudioLevelMeter level={0.6} />
<AudioLevelMeter stream={micStream} bars={7} />

Properties

NameTypeDefaultDescription

Guide

Use when

  • Showing that a microphone is live while recording or in a call.
  • Feeding back "I can hear you" before someone commits to a take.

Avoid when

  • Showing a precise reading; the bars are a glance, not an instrument.
  • Playback progress; use a scrubber.

Anatomy

A role="img" root named by label, holding bars hidden bar elements. Heights come from the CSS variable --cieo-bar on each bar.

Behavior

  • rmsLevel(samples) turns a block of samples into 0..1 on a dB scale: -60 dB or quieter is 0, 0 dB is 1, empty is 0.
  • levelBars(level, count) gives each bar a height of 0.1 to 1, tallest in the middle; helper and component output are capped at 32 bars.
  • The level is smoothed by a spring that writes CSS variables through refs, so nothing re-renders per frame.
  • With stream, the meter opens its own AudioContext and analyser in an effect and closes it on cleanup or when all input audio tracks end. It never stops host-owned tracks. level wins when both are given. A stream with no audio track leaves the meter static: the context is closed and nothing throws.
  • Reduced motion still shows the level, without easing.

Keyboard / accessibility

The root is a labelled image. The level is deliberately not announced as a changing value, because a value that changes 20 times a second is noise to a screen reader.

Do / don't

  • Do: pair it with a text state such as "Recording".
  • Don't: use it as the only sign that recording is on.

Customization

Use the typed presentation parts listed under Host customization. Defaults still use Cieo tokens; component behavior and accessibility remain owned by Cieo.

Limitations

  • Peak level only; there is no peak-hold or clipping indicator.
  • Starting a stream meter may need a user gesture before the browser lets audio run.

Related

VoiceRecorder, AudioTime.

Host customization

className adds a root class without replacing Cieo’s classes. slotProps exposes root, bar. Each part accepts className, style, title, and non-reserved data-* attributes. Roles, accessible names, values, event handlers, refs, state markers, and dynamic geometry remain component-owned. Existing content props retain their original semantics.

Best practices

Pass a stream and let the meter clean up its own analyser, or feed it a level you already measure.
Don't announce the level as a changing value; the meter is a glance, not a readout.
