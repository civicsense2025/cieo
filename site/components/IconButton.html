IconButton

Square icon-only button with a required accessible name.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { IconButton } from 'cieo/IconButton';
<IconButton label="Close"><Icon>×</Icon></IconButton>

Properties

NameTypeDefaultDescription
labelstring—Accessible name; always required.
sizesm | mdmdSquare button size.

Best practices

Do give every icon button a label naming its action.
Don't put text inside; one icon node only.
