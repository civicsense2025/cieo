GridSpan

Grid item that spans N columns (content 8 wide, rail 4 wide).

Usage

Main story

Related bills

<Grid>
  <GridSpan span={8}>Main story</GridSpan>
  <GridSpan span={4}>Related bills</GridSpan>
</Grid>

Properties

NameTypeDefaultDescription
spaninteger—Columns spanned (1-12). Required.

Best practices

Use span 8 for main content with a span 4 rail beside it.
Don't render outside Grid; the span rule only applies inside.
