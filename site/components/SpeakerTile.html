SpeakerTile

One person in a live audio room: avatar, name, a ring that swells with their voice, and muted and raised-hand badges.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { speakingStep, speakerLabel, SpeakerTile } from 'cieo/SpeakerTile';
Ava, host, speakingAAva
<SpeakerTile name="Ava" avatar={<Avatar name="Ava" initials="A" />} role="host" level={0.6} />

Properties

NameTypeDefaultDescription
namestring—Display name, shown and read aloud.
avatarReactNode—Avatar node.
levelnumber—Live loudness from 0 to 1.
mutedboolean—Shows the muted badge and keeps the ring still.
role'host' | 'speaker' | 'listener'—Role, read aloud.
handRaisedboolean—Shows the raised-hand badge.
size'sm' | 'md' | 'lg'mdTile size.
classNamestring—Additional root CSS class. Built-in classes remain.
slotPropsobject—Typed presentation parts: root, face, ring, avatar, badge, name. Accepts className, style, title and non-reserved data attributes; owned semantics and dynamic styles remain.

Best practices

Feed level from your audio stats; the tile smooths it and applies its own on and off thresholds.
Don't hide the name to save space; assistive tech reads role and state from the tile's own text.
