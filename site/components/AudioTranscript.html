AudioTranscript

Word-by-word follow-along transcript: the spoken word glides a highlight along, and words can seek the clip.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { activeWordIndex, transcriptKeyStep, shouldAutoScroll, transcriptScrollTop, AudioTranscript, TRANSCRIPT_QUIET_MS } from 'cieo/AudioTranscript';
Thanks for calling back, I will send it
<AudioTranscript words={words} current={t} onSeek={seek} label="Transcript of Voice note" />
activeWordIndex(words, 1.2) // 2

Properties

NameTypeDefaultDescription
words{ text: string; start: number; end: number }[]—Words with start and end seconds.
currentnumber—Playhead in seconds.
onSeek(seconds: number) => void—Click or Enter on a word seeks; omit for read-only.
labelstring—What the transcript is.

Best practices

Feed it the same current time as the player so both stay in step.
Don't scroll the page to the active word; the transcript follows the reader's scroll on its own.
