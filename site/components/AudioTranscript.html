AudioTranscript

Word-by-word follow-along transcript: the spoken word glides a highlight along, and words can seek the clip.

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { activeWordIndex, transcriptKeyStep, shouldAutoScroll, transcriptScrollTop, AudioTranscript, TRANSCRIPT_QUIET_MS } from 'cieo/AudioTranscript';
Thanks for calling back, I will send it
<AudioTranscript words={words} current={t} onSeek={seek} label="Transcript of Voice note" />
activeWordIndex(words, 1.2) // 2

Properties

NameTypeDefaultDescription
words{ text: string; start: number; end: number }[]—Words with start and end seconds.
currentnumber—Playhead in seconds.
onSeek(seconds: number) => void—Click or Enter on a word seeks; omit for read-only.
labelstring—What the transcript is.
classNamestring—Appended to the root classes without replacing library classes.
slotPropsobject—Typed presentation record; see TypeScript declaration. Named parts: root, word.

Guide

Use when

  • A clip has timed words and you want follow-along reading or jump-to-word.

Avoid when

  • You only have untimed text; render plain text.

Anatomy

A scrolling container with one gliding highlight and the words as inline blocks. With onSeek it is a listbox and words are options.

Behavior

  • activeWordIndex(words, t) is a binary search: -1 before the first word, and gaps keep the previous word.
  • Auto-scroll follows the active word only when the reader has not scrolled for 4 seconds.
  • Reduced motion removes the glide; the active word just changes.

Keyboard / accessibility

One tab stop. Arrow keys move a focus marker word to word (aria-activedescendant), Home and End jump, Enter or Space seeks. Click on a word seeks.

Do / don't

  • Do: give the container a height so it can scroll.
  • Don't: put words out of order; they must be sorted by start.

Customization

Colors from the accent-soft and text tokens; size the box from the host.

Limitations

  • Words must be pre-timed; no alignment is done here.

Related

AudioPlayer, AudioTime..

Host customization

className appends a root class. slotProps exposes root, word. Each part accepts className, style, title, and non-reserved data-* attributes. Existing content props and children remain the composition slots. Library classes are retained; computed inline geometry, state attributes, handlers, refs, roles, and accessibility attributes remain owned by Cieo.

Best practices

Feed it the same current time as the player so both stay in step.
Don't scroll the page to the active word; the transcript follows the reader's scroll on its own.
