ChatSystemMessage

Centered note for transcript events like joins and renames (Ava joined, Mo renamed the group).

Usage

Ava joined the conversation

<ChatMessageList label="Support thread">
  <ChatSystemMessage>Ava joined the conversation</ChatSystemMessage>
  <ChatMessage author="Ava">...</ChatMessage>
</ChatMessageList>

Properties

NameTypeDefaultDescription
default (slot)content—Event text. Text only, one line.

Best practices

Write event notes as plain facts with names and outcomes.
Don't use system notes for errors the reader must act on.
