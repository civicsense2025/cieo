AnnotationLayer

Wraps any content for pin-and-comment review: comment mode captures clicks or keyboard placement, pins are numbered, and the thread opens beside its pin.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { normalizePoint, moveReticle, escapeAction, AnnotationLayer, COMMENT_MODE_ON, COMMENT_MODE_OFF } from 'cieo/AnnotationLayer';

Page content under review

<AnnotationLayer label="Landing page" active={on} pins={pins} draft={draft}
  onPlace={setDraft} onSelect={select} selectedId={id} onActiveChange={setOn}
  renderPopover={(t) => <FeedbackPopover open ... />}>
  <Page />
</AnnotationLayer>

Properties

NameTypeDefaultDescription
labelstring—Accessible name of the reviewed area.
pins{ id: string; x: number; y: number; state?: 'open' | 'resolved'; initials?: string }[]—Existing pins, numbered in order.
activeboolean—True while comment mode is on.
onActiveChange(active: boolean) => void—Called when Escape leaves comment mode.
onPlace(point: { x: number; y: number }) => void—Called with the normalized click or reticle point.
selectedIdstring | null—Pin whose thread is open.
onSelect(id: string | null) => void—Pin pressed, or null to close the thread or draft.
renderPopover(target) => ReactNode—Content beside the draft or selected pin.
draft{ x: number; y: number } | null—The unsent pin the host created.

Best practices

Keep pins and drafts in host state in 0..1 coordinates so they survive resizing.
Don't store pixel positions; they drift when the layout changes.
