ActionBar

A toolbar for the row of actions under a post: one tab stop, arrow keys move between the buttons.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { actionBarIndex, ActionBar } from 'cieo/ActionBar';
<ActionBar label="Post actions">
  <CountButton .../>
  <CountButton .../>
</ActionBar>

Properties

NameTypeDefaultDescription
labelstring—Accessible name for the toolbar.
childrenReactNode—The buttons, in order.
size'sm' | 'md'mdSpacing to match the buttons.
align'start' | 'between'startPack left or spread across the row.
classNamestring—Appended to the root classes without replacing library classes.
slotPropsobject—Typed presentation record; see TypeScript declaration. Named parts: root.

Best practices

Use one bar per post so a long feed costs one Tab stop per row.
Don't mix links, inputs and buttons in one bar; only buttons join the arrow-key order.
