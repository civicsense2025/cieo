Components/molecule

List

Plain row collection with consistent dividers (stories, events, bills).

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { List } from 'cieo/List';
  • House passes school funding bill
  • Senate schedules vote for Thursday
<List label="Latest stories">
  <ListItem>House passes school funding bill</ListItem>
  <ListItem>Senate schedules vote for Thursday</ListItem>
</List>

Properties

NameTypeDefaultDescription
orderedbooleanfalseRender an ol when sequence matters.
labelstring—Accessible name for the list.
classNamestring—Appended to the root classes without replacing library classes.
slotPropsobject—Typed presentation record; see TypeScript declaration. Named parts: root.

Guide

Use when

  • Rows are homogeneous and share one layout (stories, events, bills).
  • Order does not matter; reach for ordered only when sequence matters.

Avoid when

  • Rows need varied layouts or grouping; that is a table or card collection, not a list.
  • You need selection semantics; that is a radio, checkbox, or select, not a list.

Anatomy

Root ul (or ol when ordered) with aria-label; ListItem rows as children. Dividers separate rows; last row has none.

Behavior

No motion. Unordered by default; ordered switches the root to ol. List never steals focus.

Keyboard / accessibility

  • Root carries the list name (aria-label, optional). Do not repeat it on rows.
  • Rows keep document order. Use ol only when sequence matters so screen readers announce position.

Do / don't

  • Do: <List label="Latest stories"> with ListItem rows of story content.
  • Don't: use ordered for decoration; numbers imply the sequence matters.

Customization

Ordered flag only. Spacing, dividers, and colors come from Cieo tokens; do not restyle rows per instance.

Limitations

  • Homogeneous rows only. Mixed layouts need a different primitive.
  • No selection or expansion semantics; host owns row content and actions.

Related

ListItem (atom), Table (lane plan), Card (organism).

Host customization

className appends a root class. slotProps exposes root. Each part accepts className, style, title, and non-reserved data-* attributes. Existing content props and children remain the composition slots. Library classes are retained; computed inline geometry, state attributes, handlers, refs, roles, and accessibility attributes remain owned by Cieo.

Best practices

Use ListItem rows of story content under a labelled List.
Don't use ordered for decoration; numbers imply sequence matters.
