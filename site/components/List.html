Components · molecule

List

Plain row collection with consistent dividers (stories, events, bills).

Usage

  • House passes school funding bill
  • Senate schedules vote for Thursday
<List label="Latest stories">
  <ListItem>House passes school funding bill</ListItem>
  <ListItem>Senate schedules vote for Thursday</ListItem>
</List>

Properties

NameTypeDefaultDescription
orderedbooleanfalseRender an ol when sequence matters.
labelstring—Accessible name for the list.

Best practices

Use ListItem rows of story content under a labelled List.
Don't use ordered for decoration; numbers imply sequence matters.
