AuthInviteAccept

Org invite card with org-named accept and decline actions.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { AuthInviteAccept } from 'cieo/AuthInviteAccept';

You're invited

Priya invited you to join Acme Studio as Editor.

<AuthInviteAccept id="invite" orgName="Acme Studio" inviterName="Priya" role="Editor" onAccept={accept} onDecline={decline} />

Properties

NameTypeDefaultDescription
idstring—Binds the card heading.
orgNamestring—Workspace named on both action buttons.
inviterNamestring—Person who sent the invite.
rolestring—Role the invite grants.
pendingbooleanfalseDisables both actions while accepting.
errorstring—Error text.
onAcceptfunction—Fires on accept.
onDeclinefunction—Fires on decline.

Best practices

Do name the org on both buttons so each action is clear out of context.
Don't confirm a decline with colour alone; say what happened in text.
