BottomSheet

Bottom-anchored dialog sheet for short choices on narrow screens (share options, sort order).

Usage

Sort order

<BottomSheet label="Sort order" open onClose={close}>
  <DialogHeader title="Sort order" onClose={close} />
  <button>Newest first</button>
  <button>Oldest first</button>
</BottomSheet>

Properties

NameTypeDefaultDescription
labelstring—Accessible name for the sheet. Required.
openboolean—Whether the sheet is open. Renders null when false or omitted.
onClosefunction—Called on Escape or host close affordances.

Best practices

Keep sheet content short and thumb-reachable for small screens.
Don't stack sheets; close the first before opening the next.
