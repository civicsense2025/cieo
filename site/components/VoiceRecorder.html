VoiceRecorder

Records a voice clip from the microphone and hands the host a blob with its length and waveform peaks.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { isRecorderActive, voiceRecorderStep, shouldEmitClip, pickRecorderMimeType, downsamplePeaks, holdGesture, remainingSeconds, isNearLimit, recorderAnnouncement, VoiceRecorder, recorderIdle, HOLD_CANCEL_DISTANCE } from 'cieo/VoiceRecorder';
<VoiceRecorder
  maxDuration={90}
  onRecorded={({ blob, duration, peaks }) => upload(blob, duration, peaks)}
/>

Properties

NameTypeDefaultDescription
onRecorded(clip: { blob: Blob; mimeType: string; duration: number; peaks: number[] }) => void—Called once with the finished clip. Never after a cancel.
onCancel() => void—Called when an active take is cancelled.
maxDurationnumber120Longest take in seconds; stops by itself at the limit.
autoStartbooleanfalseAsk for the microphone on mount.
labelstringRecord a voice replyAccessible name of the recorder.
mode'tap' | 'hold'taptap: press to start and stop. hold: record while held, slide left to cancel.

Best practices

Upload the clip in onRecorded and show it with an AudioPlayer using the same peaks.
Don't keep the recorder mounted just to hide it; unmounting releases the microphone.
