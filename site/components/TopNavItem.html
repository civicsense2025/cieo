TopNavItem

Single link in the top nav; marks the current page.

Usage

Docs
<TopNavItem href="/docs" current>Docs</TopNavItem>

Properties

NameTypeDefaultDescription
hrefstring—Link target.
currentbooleanfalseCurrent page state; renders aria-current=page.

Best practices

Mark the current page with current on exactly one item per nav.
Don't set current on two items in the same nav.
