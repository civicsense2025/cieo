ClickableCard

Article card where one stretched link makes the whole card navigate (a help article teaser).

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { ClickableCard } from 'cieo/ClickableCard';

Refund timelines

Most refunds land in 5–10 days.

Read the guide
<ClickableCard>
  <h2>Refund timelines</h2>
  <p>Most refunds land in 5–10 days.</p>
  <a href="/help/refunds">Read the guide</a>
</ClickableCard>

Best practices
