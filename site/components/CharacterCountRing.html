CharacterCountRing

A ring that fills as a text limit is used, grows and counts down near the limit, and turns danger past it.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { ringState, ringAnnouncement, CharacterCountRing } from 'cieo/CharacterCountRing';
1212 characters left-33 characters over the limit
<CharacterCountRing length={268} max={280} />
ringState(283, 280) // { fraction: 1, remaining: -3, tone: "danger", showNumber: true }

Properties

NameTypeDefaultDescription
lengthnumber—Characters used so far.
maxnumber—The limit.
warnAtnumber20Remaining characters at which the ring warns and shows the countdown.
classNamestring—Additional root CSS class. Built-in classes remain.
slotPropsobject—Typed presentation parts: root, track, arc, number. Accepts className, style, title and non-reserved data attributes; owned semantics and dynamic styles remain.

Best practices

Show it once most of the limit is used; the ring is for the last stretch.
Don't announce it live on every keystroke; the hidden sentence is read when the ring is reached.
