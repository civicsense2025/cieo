ConversationList

The inbox: rows with one tab stop, arrow-key movement, and rows that glide to their new places when the order changes.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { conversationIds, conversationOrder, conversationTabbable, conversationRove, ConversationList, ConversationListContext } from 'cieo/ConversationList';
<ConversationList label="Conversations" order={ids} selectedId={openId}>
  {rows.map((c) => <ConversationListItem key={c.id} {...c} />)}
</ConversationList>

Properties

NameTypeDefaultDescription
labelstring—Accessible name for the list.
orderstring[]—Conversation ids in display order; rows glide when it changes.
selectedIdstring—Id of the open conversation.

Best practices

Keep `order` the single source of row order; update it when a message arrives and the row glides to the top.
Don't re-key rows to reorder them; that remounts them and loses focus.
