AudioPlayButton

Round play/pause button whose icon morphs between the two shapes, with a ring while the clip loads.

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { audioPlayButtonName, AudioPlayButton } from 'cieo/AudioPlayButton';
<AudioPlayButton playing={playing} label="Voice note" onToggle={toggle} />

Properties

NameTypeDefaultDescription
playingboolean—True while the clip plays; the button then offers Pause.
loadingbooleanfalseShows a ring and sets aria-busy.
labelstring—Name of the clip, read after Play or Pause.
onToggle() => void—Called when the button is pressed.
size'sm' | 'md' | 'lg'mdButton size.
playLabelstring"Play"Optional.
pauseLabelstring"Pause"Optional.
classNamestring—Additional root CSS class. Built-in classes remain.
slotPropsobject—Typed presentation parts: root, icon, pauseHalf, ring. Accepts className, style, title and non-reserved data attributes; owned semantics and dynamic styles remain.

Guide

Use when

  • Any audio control needs a play/pause toggle: players, recorders reviewing a take, transcripts.

Avoid when

  • A generic toggle with no clip; use IconButton with aria-pressed.

Anatomy

A native button holding an icon (two clipped halves that reshape) and a ring. Sizes sm, md, lg.

Behavior

  • The accessible name is Play {label} or Pause {label}; audioPlayButtonName builds it. Pass playLabel and pauseLabel to read the verbs in the host's language.
  • loading shows the ring and sets aria-busy; the button stays pressable.
  • The icon morphs with a CSS transition on the spring ease; reduced motion swaps instantly.

Keyboard / accessibility

Real button: Space and Enter activate it. Focus ring on :focus-visible. Hit target is at least the touch target on touch screens.

Do / don't

  • Do: pass the clip's name as label.
  • Don't: hide the clip name; "Play" alone is ambiguous in a list of notes.

Customization

Use the typed presentation parts listed under Host customization. Defaults still use Cieo tokens; component behavior and accessibility remain owned by Cieo.

Limitations

  • Does not own audio; pair with AudioPlayer.

Related

AudioPlayer, IconButton, AudioWaveform..

Host customization

className adds a root class without replacing Cieo’s classes. slotProps exposes root, icon, pauseHalf, ring. Each part accepts className, style, title, and non-reserved data-* attributes. Roles, accessible names, values, event handlers, refs, state markers, and dynamic geometry remain component-owned. Existing content props retain their original semantics.

Best practices

Name the clip in label so the button reads "Play Voice note from Ana".
Don't swap the icon yourself; the button morphs it from the playing prop.
