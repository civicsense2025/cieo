CommandPaletteInput

Filter field for CommandPalette with a visually hidden label.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { CommandPaletteInput } from 'cieo/CommandPaletteInput';
<CommandPaletteInput label="Filter commands" value={query} onChange={setQuery} placeholder="Type to filter…" />

Properties

NameTypeDefaultDescription
labelstring—Accessible name for the filter field.
valuestring—Controlled filter text.
onChangefunction—Host filter hook.
placeholderstring—Short hint shown when empty.

Best practices

Bind value and onChange to the same host query state as the palette.
Don't add a second visible label; the hidden label already names the field.
