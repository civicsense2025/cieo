CheckboxInput

Single checkbox under its Astryx name: a thin contract over the Checkbox control.

Usage

import { CheckboxInput } from '../../primitives/CheckboxInput/CheckboxInput.js';

<CheckboxInput label="Email updates" />

Properties

NameTypeDefaultDescription
labelstring—Visible name of the checkbox.
hideLabelbooleanfalseKeep the label for assistive tech only.
descriptionstring—Extra help text bound via aria-describedby.
indeterminatebooleanfalseMixed state for partial selections.

Best practices

Import CheckboxInput wherever Astryx names a single checkbox.
Don't fork checkbox behavior here; change the Checkbox control instead.
