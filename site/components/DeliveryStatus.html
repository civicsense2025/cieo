DeliveryStatus

Where one sent message is on its way: an icon that changes shape from clock to check to double check, with a spoken status.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { deliveryLabel, DeliveryStatus } from 'cieo/DeliveryStatus';
Sending Sent Delivered Read Not deliveredNot delivered
<DeliveryStatus status="read" time="9:41 AM" />
deliveryLabel("failed") // "Not delivered"

Properties

NameTypeDefaultDescription
status'sending' | 'sent' | 'delivered' | 'read' | 'failed'—Where the message is.
timestring—Optional time text beside the icon, read after the status.
classNamestring—Additional root CSS class. Built-in classes remain.
slotPropsobject—Typed presentation parts: root, icon, glyph, text, time. Accepts className, style, title and non-reserved data attributes; owned semantics and dynamic styles remain.

Best practices

Keep the status in sync with what the server confirmed; the icon animates between states.
Don't rely on color alone for read; the double check shape and the spoken word carry it too.
