LayoutFooter

App frame footer landmark, unstyled by design (legal links, colophon).

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { LayoutFooter } from 'cieo/LayoutFooter';

Session data: public record. About this tracker

<Layout>
  …
  <LayoutFooter>
    Session data: public record. <a href="/about">About</a>
  </LayoutFooter>
</Layout>

Properties

NameTypeDefaultDescription
labelstring—Accessible name for the footer landmark.
classNamestring—Additional root CSS class. Built-in classes remain.
slotPropsobject—Typed presentation parts: root. Accepts className, style, title and non-reserved data attributes; owned semantics and dynamic styles remain.

Best practices

Put legal links and colophon inside the footer within a Layout frame.
Don't style it per page here; the host owns footer paint.
