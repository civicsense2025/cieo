NumberInput

Labelled numeric field: one native number input reusing the shared input style.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { NumberInput } from 'cieo/NumberInput';
<NumberInput label="Quantity" min={1} max={10} defaultValue={1} />

Properties

NameTypeDefaultDescription
labelstring—Visible label for the field.
minnumber—Minimum value.
maxnumber—Maximum value.
stepnumber—Step between values.
defaultValuenumber—Initial uncontrolled value.

Best practices

Use it for real numbers with declarative min and max.
Don't use it for ZIP codes or phone numbers; text preserves formatting.
