NumberInput

Labelled numeric field: one native number input reusing the shared input style.

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { NumberInput } from 'cieo/NumberInput';
<NumberInput label="Quantity" min={1} max={10} defaultValue={1} />

Properties

NameTypeDefaultDescription
labelstring—Visible label for the field.
minnumber—Minimum value.
maxnumber—Maximum value.
stepnumber—Step between values.
defaultValuenumber—Initial uncontrolled value.
classNamestring—Additional root CSS class. Built-in classes remain.
slotPropsobject—Typed presentation parts: root, label, input. Accepts className, style, title and non-reserved data attributes; owned semantics and dynamic styles remain.

Guide

Use when

  • The form needs a real number (quantity, seats, retry count).
  • Min, max, or step constraints can stay declarative and native.

Avoid when

  • The value is numeric-looking text (ZIP, phone, card number); use a text input so leading zeros and spacing survive.
  • You need a slider with live readout; that is a Slider.

Anatomy

Wrapping <label>: visible .cieo-label span plus <input type="number" class="cieo cieo-input">. No new CSS; the input face comes from design/styles/controls.css.

Behavior

No motion. Native spinners and keyboard stepping; defaultValue sets the uncontrolled initial value.

Keyboard / accessibility

  • Label wraps the input, so label focus works without an id.
  • Native number keyboard support (arrows step); out-of-range values fail native validation with the platform message.

Do / don't

  • Do: <NumberInput label="Quantity" min={1} max={10} defaultValue={1} />.
  • Don't: use NumberInput for ZIP codes or phone numbers; text preserves formatting.

Customization

Use the typed presentation parts listed under Host customization. Defaults still use Cieo tokens; component behavior and accessibility remain owned by Cieo.

Limitations

  • Uncontrolled only (defaultValue); controlled value state lives in the host.
  • Spinner and locale formatting are platform-owned and vary by browser.

Related

Slider (atom, for ranged choice with readout), Field (molecule, for the label/help row), FieldStatus (atom, for the help/error line).

Host customization

className adds a root class without replacing Cieo’s classes. slotProps exposes root, label, input. Each part accepts className, style, title, and non-reserved data-* attributes. Roles, accessible names, values, event handlers, refs, state markers, and dynamic geometry remain component-owned. Existing content props retain their original semantics.

Best practices

Use it for real numbers with declarative min and max.
Don't use it for ZIP codes or phone numbers; text preserves formatting.
