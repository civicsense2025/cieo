UnreadDivider

A rule with a centered accent label that marks where unread messages begin.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { unreadDividerLabel, UnreadDivider } from 'cieo/UnreadDivider';
3 new messages
<UnreadDivider count={3} />
unreadDividerLabel(1) // "1 new message"

Properties

NameTypeDefaultDescription
countnumber—How many messages are unread. Becomes part of the label when no label is given.
labelstringNew messagesReplaces the wording entirely.
classNamestring—Additional root CSS class. Built-in classes remain.
slotPropsobject—Typed presentation parts: root, rule, label. Accepts className, style, title and non-reserved data attributes; owned semantics and dynamic styles remain.

Best practices

Place it once, right before the first unread message, and remove it once the conversation is read.
Don't repeat it between every unread message.
