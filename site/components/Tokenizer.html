Tokenizer

Token chips plus an add input; host owns the value list.

Usage

budget voting 
<Tokenizer label="Tags" values={tags} onRemove={(i) => setTags(tags.filter((_, n) => n !== i))} onAdd={(t) => setTags([...tags, t])} />

Properties

NameTypeDefaultDescription
labelstring—Visible label naming the set.
valuesarray—Current tokens, owned by the host.
onRemovefunction—Host remove hook by index.
onAddfunction—Host add hook with trimmed input text.

Best practices

Name every remove button Remove plus the value; Enter adds the draft.
Don't import Lane Content's Token for chips; cross-lane imports are forbidden.
