ToggleButtonGroup

Single-select group of toggle buttons, for one alignment out of left, center, and right.

Usage

import { ToggleButtonGroup } from 'cieo';
import { ToggleButton } from 'cieo';
const [align, setAlign] = useState('left');
<ToggleButtonGroup label="Text alignment" value={align} onValueChange={setAlign}>
  <ToggleButton label="Align left" value="left">Left</ToggleButton>
  <ToggleButton label="Align center" value="center">Center</ToggleButton>
  <ToggleButton label="Align right" value="right">Right</ToggleButton>
</ToggleButtonGroup>

Properties

NameTypeDefaultDescription
labelstring—Accessible name for the group.
valuestring—Selected button value when controlled.
defaultValuestring—Initial selected value when uncontrolled.
onValueChange(value: string) => void—Called with the newly selected value.

Best practices

Give every child ToggleButton a unique value key so selection can reach it.
Do not use the group for multi-select; use standalone ToggleButtons instead.
