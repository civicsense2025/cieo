Rating

A star rating: a radio group the viewer can set, or a read-only summary.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { ratingKeyStep, ratingLabel, ratingPopDelays, Rating } from 'cieo/Rating';
<Rating value={rating} onChange={setRating} label="Rate this reply" />

Properties

NameTypeDefaultDescription
valuenumber—Current rating, 0 for none.
onChange(value: number) => void—Called with the picked rating.
maxnumber5Number of stars.
labelstring—What is being rated.
readOnlyboolean—Shows the rating as an image.
size'sm' | 'md'mdStar size.

Best practices

Use readOnly for averages and past ratings.
Don't show fractions in the interactive mode; only whole stars can be picked.
