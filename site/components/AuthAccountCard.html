AuthAccountCard

Profile row with sign out guarded by an inline confirm step.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { AuthAccountCard } from 'cieo/AuthAccountCard';

Best practices

Do confirm bulk sign-out inline with Confirm and Cancel buttons.
Don't sign out of every device on a single unguarded tap.
