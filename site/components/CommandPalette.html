CommandPalette

Controlled command-menu shell; the host filters items from the query.

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { CommandPalette, CommandPaletteContext } from 'cieo/CommandPalette';

  <CommandPaletteInput label="Filter commands" value={query} onChange={setQuery} />

Properties

NameTypeDefaultDescription
labelstring—Accessible name for the palette.
querystring—Current filter text, owned by the host.
onQueryChangefunction—Host filter hook, wired to the input onChange.
classNamestring—Appended to the root classes without replacing library classes.
slotPropsobject—Typed presentation record; see TypeScript declaration. Named parts: root.

Guide

Use when

  • A ⌘K-style menu jumps between pages, actions, or records.
  • The host already owns the item list and can filter it from query text.

Avoid when

  • The list is short and static; a plain menu or select needs no filter shell.
  • You need modal focus trapping; this is a panel, not a dialog manager.

Anatomy

Root role="dialog" with aria-label; host composes Input, List, Groups, Items, Empty, and Footer inside.

Behavior

No motion. query is host state; onQueryChange wires to the input. The shell never filters children itself.

Keyboard / accessibility

  • Root carries the palette name (aria-label, required); items keep role="option".
  • Full keyboard travel (arrow keys, Enter) is host-owned; keep one tab stop into the palette.

Do / don't

  • Do: <CommandPalette label="Site commands"> with the host filtering items from query.
  • Don't: pre-filter children and also pass query; one owner or the count lies.

Customization

Panel paint only. Radius, border, and surface come from Cieo tokens; do not restyle per instance.

Limitations

  • No positioning or flip; the host places the panel.
  • No persistence; the host owns open state and recent items.

Related

CommandPaletteInput (atom), CommandPaletteList (molecule), Popover (molecule).

Host customization

className appends a root class. slotProps exposes root. Each part accepts className, style, title, and non-reserved data-* attributes. Existing content props and children remain the composition slots. Library classes are retained; computed inline geometry, state attributes, handlers, refs, roles, and accessibility attributes remain owned by Cieo.

Best practices

Filter items from query in the host and render only matches.
Don't pre-filter children and pass query; one owner or the count lies.
