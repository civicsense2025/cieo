DropdownMenuRadioItem

One pick inside a menu radio group, checked when the group value matches.

Usage

import { DropdownMenuRadioGroup } from 'cieo';
import { DropdownMenuRadioItem } from 'cieo';
<DropdownMenuRadioGroup value={order} onValueChange={setOrder}>
  <DropdownMenuRadioItem label="Newest first" value="newest" />
  <DropdownMenuRadioItem label="Oldest first" value="oldest" />
</DropdownMenuRadioGroup>

Properties

NameTypeDefaultDescription
labelstring—Accessible name and visible text for the option.
valuestring—Option key matched against the group value.

Best practices

Keep option labels parallel so the checked one is easy to compare.
Do not render it outside a DropdownMenuRadioGroup; it never checks there.
