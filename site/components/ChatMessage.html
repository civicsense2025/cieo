Components/molecule

ChatMessage

One transcript entry with optional author and time (a reply from Ava at 9:41 AM).

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { ChatMessage } from 'cieo/ChatMessage';
Ava 9:41 AM
Your refund of $42.18 is on its way.
<ChatMessage author="Ava" time="9:41 AM">
  <ChatMessageBubble>Your refund of $42.18 is on its way.</ChatMessageBubble>
</ChatMessage>

Properties

NameTypeDefaultDescription
authorstring—Message author name.
timestring—Message timestamp.
classNamestring—Appended to the root classes without replacing library classes.
slotPropsobject—Typed presentation record; see TypeScript declaration. Named parts: root, author, time.

Guide

Use when

  • Rendering one message inside a ChatMessageList transcript.
  • The entry needs an author or timestamp line above its bubble.

Avoid when

  • The note is from the system, not a participant; use ChatSystemMessage instead.
  • The line is metadata without a body; use ChatMessageMetadata instead.

Anatomy

article root with optional author span, optional time, then host body (usually a ChatMessageBubble).

Behavior

No motion. Static container; delivery state and retries belong to the host.

Keyboard / accessibility

  • Article groups one message so screen readers move entry by entry.
  • Time uses a real <time> element; author is plain text, never a heading.

Do / don't

  • Do: <ChatMessage author="Ava" time="9:41 AM"> with a bubble child.
  • Don't: nest messages inside messages; siblings belong to the list.

Customization

None per instance. Spacing and type come from Cieo tokens.

Limitations

  • No bubble styling of its own; pair with ChatMessageBubble for the visible bubble.
  • No status (sent, read); the host adds that beside the body when needed.

Related

ChatMessageBubble (atom), ChatMessageList (organism), ChatMessageMetadata (atom), ChatSystemMessage (atom).

Host customization

className appends a root class. slotProps exposes root, author, time. Each part accepts className, style, title, and non-reserved data-* attributes. Existing content props and children remain the composition slots. Library classes are retained; computed inline geometry, state attributes, handlers, refs, roles, and accessibility attributes remain owned by Cieo.

Best practices

Pair each message with a bubble so entries read as distinct turns.
Don't nest messages inside messages; keep siblings flat in the list.
