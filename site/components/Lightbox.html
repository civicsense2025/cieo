Lightbox

Image viewer dialog for inspecting one picture at full size (a receipt photo, a chart).

Usage

<Lightbox src="receipt.jpg" alt="Grocery receipt totaling $42.18" open onClose={close} />

Properties

NameTypeDefaultDescription
srcstring—Image source. Required.
altstring—Image alternative text. Required.
openboolean—Whether the viewer is open. Renders null when false or omitted.
onClosefunction—Called on Escape or host close affordances.
labelstringImage viewerAccessible name for the viewer dialog.

Best practices

Describe what the image shows in alt text so the viewer stands alone.
Don't pass empty alt text to silence the requirement.
