DropdownMenuItem

Single menu action that runs and usually closes the menu.

Usage

import { DropdownMenuItem } from 'cieo';
<DropdownMenuItem label="Rename" onSelect={() => { rename(); setOpen(false); }}>
  Rename
</DropdownMenuItem>

Properties

NameTypeDefaultDescription
labelstring—Accessible name when children carry no readable text.
disabledbooleanfalseRemoves the item from selection.
onSelect() => void—Called when the host should run the action.

Best practices

Name rows verb-first so scanners know what each row does.
Do not nest buttons or links inside the row; the whole row is the button.
