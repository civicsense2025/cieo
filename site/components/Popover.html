Popover

Controlled disclosure shell with a simple absolute panel below the trigger.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { Popover } from 'cieo/Popover';
Copy link
<Popover trigger={<button>Share</button>} open={open} onOpenChange={setOpen}>
  <a href="#">Copy link</a>
</Popover>

Don't depend on edge flipping; the panel always sits below the trigger.
