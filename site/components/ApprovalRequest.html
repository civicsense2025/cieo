ApprovalRequest

Asks a person to approve or deny an agent action, never optimistically.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { ApprovalRequest, APPROVAL_STATUS_WORDS } from 'cieo/ApprovalRequest';

Waiting for your decision

<ApprovalRequest approval={approval} busy={busy} onApprove={approve} onDeny={deny} />

Properties

NameTypeDefaultDescription
approvalApprovalView—The approval as the host reported it.
onApprove() => void—Sends the approve command to the host. The view changes only when the host resolves it.
onDeny() => void—Sends the deny command to the host.
busy'approve' | 'deny' | null—Which command is in flight, or null. While set, both buttons are disabled.
approveLabelstringApproveApprove button text. Defaults to "Approve".
denyLabelstringDenyDeny button text. Defaults to "Deny".
fallbackTitlestringApproval neededTitle shown when the approval has none. Defaults to "Approval needed".
headingLevel2 | 3 | 4 | 5 | 63Heading level for the title, 2 to 6. Defaults to 3.

Best practices

Do set busy while the command is in flight.
Don't show a decision before the host resolves it.
