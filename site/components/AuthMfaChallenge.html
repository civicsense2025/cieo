AuthMfaChallenge

OTP plus verify, with a recovery-code fallback.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { AuthMfaChallenge } from 'cieo/AuthMfaChallenge';
<AuthMfaChallenge id="mfa" onSubmit={verify} onRecovery={recover} />

Properties

NameTypeDefaultDescription

errorstring—Error text with role alert.
onSubmitfunction—Receives the code.
onRecoveryfunction—Receives the recovery code.
classNamestring—Appended to the root classes without replacing library classes.
slotPropsobject—Typed presentation record; see TypeScript declaration. Named parts: root, recovery, label, input, submit, toggle.

Best practices

Do offer the recovery path next to the code boxes.
Don't clear the code without telling the person why.
