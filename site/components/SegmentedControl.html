SegmentedControl

Single-select pill of segments, for day, week, and month views of one panel.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { SegmentedControl, SegmentedControlContext } from 'cieo/SegmentedControl';
import { SegmentedControl } from 'cieo';
import { SegmentedControlItem } from 'cieo';
const [view, setView] = useState('day');
<SegmentedControl label="Calendar view" value={view} onValueChange={setView}>
  <SegmentedControlItem value="day">Day</SegmentedControlItem>
  <SegmentedControlItem value="week">Week</SegmentedControlItem>
  <SegmentedControlItem value="month">Month</SegmentedControlItem>
</SegmentedControl>

Properties

NameTypeDefaultDescription
labelstring—Accessible name for the control.
valuestring—Picked segment value when controlled.
defaultValuestring—Initial picked value when uncontrolled.
onValueChange(value: string) => void—Called with the newly picked value.
classNamestring—Appended to the root classes without replacing library classes.
slotPropsobject—Typed presentation record; see TypeScript declaration. Named parts: root.

Best practices

Keep segment text to one or two words so the pill never overflows.
Do not use segments for page navigation; use tabs or links instead.
