ReferenceText

A reference read as data: a section number or a page count, in the mono reference style.

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { pageBounds, ReferenceText } from 'cieo/ReferenceText';
4/18
<ReferenceText spoken="Page 4 of 18">4/18</ReferenceText>

Properties

NameTypeDefaultDescription
childrenobject—Required.
spokenstring—Replaces the visible text for screen readers, such as "Page 4 of 18".
classNamestring—Additional root CSS class. Built-in classes remain.
slotPropsobject—Typed presentation parts: root. Accepts className, style, title and non-reserved data attributes; owned semantics and dynamic styles remain.

Guide

Use when

  • A section number (§1302) or a page count (4/18).

Avoid when

  • The text is a label or heading; use TopicChip or Heading.

Anatomy

Root span.cieo-p-reference-text.

Behavior

pageBounds(page, total) clamps a page count so it never shows page 0 or a page past the total.

Keyboard / accessibility

  • Pass spoken for counts so "4/18" reads "Page 4 of 18".

Do / don't

  • Do: <ReferenceText spoken="Page 4 of 18">4/18</ReferenceText>
  • Don't: Don't set it in uppercase.
