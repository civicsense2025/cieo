Dialog

Controlled modal panel over a scrim for short tasks (rename a file, confirm a choice).

Usage

Rename file

<Dialog label="Rename file" open onClose={close}>
  <DialogHeader title="Rename file" onClose={close} />
  <label>New name <input value={name} onChange={setName} /></label>
  <p><button>Save</button> <button>Cancel</button></p>
</Dialog>

Properties

NameTypeDefaultDescription
labelstring—Accessible name for the dialog. Required.
openboolean—Whether the dialog is open. Renders null when false or omitted.
onClosefunction—Called on Escape or host close affordances.

Best practices

Give every dialog an accessible label naming its task.
Don't open a dialog from another dialog; close the first one first.
