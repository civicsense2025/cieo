SegmentedControlItem

One segment inside a segmented control, pressed when the control value matches.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { SegmentedControlItem } from 'cieo/SegmentedControlItem';
import { SegmentedControlItem } from 'cieo';
<SegmentedControl label="Calendar view" value={view} onValueChange={setView}>
  <SegmentedControlItem value="day">Day</SegmentedControlItem>
  <SegmentedControlItem value="week">Week</SegmentedControlItem>
</SegmentedControl>

Properties

NameTypeDefaultDescription
valuestring—Segment key matched against the control value.
classNamestring—Additional root CSS class. Built-in classes remain.
slotPropsobject—Typed presentation parts: root. Accepts className, style, title and non-reserved data attributes; owned semantics and dynamic styles remain.

Best practices

Keep one short text node per segment so the pill stays balanced.
Do not render it outside a SegmentedControl; it never presses there.
