AgentIcon

One agent action or state icon at rest, in currentColor.

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { AgentIcon } from 'cieo/AgentIcon';
Browsing Failed
<AgentIcon icon="browsing" /> Browsing

Properties

NameTypeDefaultDescription
iconAgentIconId | AgentIconDefinition—Icon id (e.g. "browsing") or a definition from AGENT_ICONS.
sizenumber24Rendered size in pixels. Picks the glyph detail and stroke weight. Defaults to 24.
labelstring—Accessible name. Omit when visible text beside the icon names it.
outlinebooleantrueDraw the agent's square outline. Defaults to true.
classNamestring—Additional root CSS class. Built-in classes remain.
slotPropsobject—Typed presentation parts: root. Accepts className, style, title and non-reserved data attributes; owned semantics and dynamic styles remain.

Guide

Use when

  • A row or lane needs a compact picture of what an agent is doing, beside words that say it.

Avoid when

  • You need the animated loops; use the agent icon atom in atoms/web/identity.
  • The icon would be the only cue; add visible text or a label.

Anatomy

svg.cieo.cieo-p-agent-icon[data-icon][data-tone] (64-unit viewBox) → the agent's square outline and a stroked glyph group.

Behavior

Static. size picks one of three glyph details (20px and below, up to 24px, larger) and a stroke weight that stays about 1.55px. Status icons (failed, done, blocked and others) take their tone colour from tokens.

Keyboard / accessibility

  • Decorative (aria-hidden) unless label is set; then role="img" with that name.

Do / don't

  • Do: <AgentIcon icon="browsing" /> Browsing.
  • Don't: use an icon's colour as the only signal of failure.

Customization

Use the typed presentation parts listed under Host customization. Defaults still use Cieo tokens; component behavior and accessibility remain owned by Cieo.

Limitations

  • Product form only. The brand form (paper tile and wash) stays in the atom.
  • An unknown id renders nothing.

Related

AgentStatus, Icon, cieo/agent-icons.

Host customization

className adds a root class without replacing Cieo’s classes. slotProps exposes root. Each part accepts className, style, title, and non-reserved data-* attributes. Roles, accessible names, values, event handlers, refs, state markers, and dynamic geometry remain component-owned. Existing content props retain their original semantics.

Best practices

Do pair the icon with words.
Don't use its colour as the only signal.

Tokens
