AgentIcon

One agent action or state icon at rest, in currentColor.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { AgentIcon } from 'cieo/AgentIcon';

<AgentIcon icon="browsing" /> Browsing

Properties

NameTypeDefaultDescription
iconAgentIconId | AgentIconDefinition—Icon id (e.g. "browsing") or a definition from AGENT_ICONS.
sizenumber24Rendered size in pixels. Picks the glyph detail and stroke weight. Defaults to 24.
labelstring—Accessible name. Omit when visible text beside the icon names it.
outlinebooleantrueDraw the agent's square outline. Defaults to true.

Best practices

Do pair the icon with words.
Don't use its colour as the only signal.
