AudioPlayer

One audio clip with play/pause, a waveform or progress scrubber, a clock and speed; only one plays at a time per page.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { audioPlayerStep, createAudioPlayerToken, registerAudioPlayer, claimAudioPlayback, AudioPlayer, AUDIO_PLAY_EVENT } from 'cieo/AudioPlayer';
1:031 minute 3 seconds
<AudioPlayer src={url} label="Voice note from Ana" peaks={peaks} duration={63} />

Properties

NameTypeDefaultDescription
srcstring—URL of the audio file.
labelstring—What the clip is; names the player and its buttons.
peaksnumber[]—Samples for a waveform scrubber; without them a thin track is drawn.
durationnumber—Known length in seconds, used before metadata loads.
variant'compact' | 'full'compactcompact is the voice-note pill; full adds speed and time left.
ratesnumber[]1, 1.5, 2Speeds for the full variant.
onPlay() => void—Playback started.
onPause() => void—Playback paused.
onEnded() => void—Clip reached its end.
onTimeUpdate(seconds: number) => void—Playhead, about four times a second.
classNamestring—Appended to the root classes without replacing library classes.
slotPropsobject—Typed presentation record; see TypeScript declaration. Named parts: error, retry, track, root, main, times.

Best practices

Use compact inside comments and message bubbles, full on a page of its own.
Don't render your own audio element next to it; starting another player pauses this one.
