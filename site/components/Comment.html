Comment

One post in a thread: avatar, byline, body and slots for attachments, actions and nested replies, with a rail that curves into each reply.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { commentDepth, commentHasRail, Comment } from 'cieo/Comment';
GT
ginandtanic◎›midterms 2026·1d
Turnout in the primaries looks very different from last cycle.
AV
Ava·3h
Agreed, the early vote is the story.
<Comment author="ginandtanic" avatar={<Avatar name="ginandtanic" initials="GT" />} time="1d" actions={<Actions />} replies={replies}>
  Turnout looks very different.
</Comment>

Best practices

Put audio players, link cards and images in `attachments`, and any buttons in `actions`.
Don't build the reply tree by hand; let CommentThread pass `replies` and `depth`.
