Section

Page subdivision with an optional title heading (settings groups, article chapters).

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { Section } from 'cieo/Section';

Notifications

Email me when a bill I follow moves chambers.

<Section title="Notifications">
  <p>Email me when a bill I follow moves chambers.</p>
</Section>

Properties

NameTypeDefaultDescription
titlestring—Visible title rendered as a heading.
labelstring—Accessible name when there is no visible title.

Best practices

Use one Section per page topic with a visible title.
Don't nest sections three deep to fake card padding.
