AuthSsoButtons

One button per identity provider; pending shows by text change plus aria-busy.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { AuthSsoButtons } from 'cieo/AuthSsoButtons';
<AuthSsoButtons id="sso" providers={[{id:"google",label:"Google"}]} onPress={go} />

Properties

NameTypeDefaultDescription
idstring—Group prefix; each button binds {id}-{providerId}.
providersarray—One button per {id, label} entry.
pendingIdstring—Provider with a redirect in flight.
onPressfunction—Fires with the pressed provider id.
classNamestring—Appended to the root classes without replacing library classes.
slotPropsobject—Typed presentation record; see TypeScript declaration. Named parts: root, ssoButton.

Best practices

Do give every provider button its own accessible name.
Don't signal the pending redirect by colour alone.
