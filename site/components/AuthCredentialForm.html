AuthCredentialForm

Email plus password plus submit for sign in and sign up.

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { AuthCredentialForm } from 'cieo/AuthCredentialForm';
<AuthCredentialForm id="signin" mode="signin" onSubmit={signIn} />

Properties

NameTypeDefaultDescription
idstring—Form id; field ids derive from it.
modesignin | signupsigninSignup shows the strength meter.
pendingbooleanfalseDisables the submit while set.
errorstring—Form-level error with role alert.
onSubmitfunction—Receives { email, password }.
classNamestring—Appended to the root classes without replacing library classes.
slotPropsobject—Typed presentation record; see TypeScript declaration. Named parts: root, submit.

Guide

Host customization

className appends a root class. slotProps exposes root, submit. Each part accepts className, style, title, and non-reserved data-* attributes. Existing content props and children remain the composition slots. Library classes are retained; computed inline geometry, state attributes, handlers, refs, roles, and accessibility attributes remain owned by Cieo.

Best practices

Do disable the submit while pending so double clicks never fire twice.
Don't validate on submit only; the fields validate on input.
