AudioRoom

The shell of a live audio room: title and listener count, a stage of speakers that glide into place, and the controls for the person using it.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { stageKey, AudioRoom } from 'cieo/AudioRoom';

Best practices

Keep speaker ids stable so the stage can slide people into place.
Don't use it for video calls; it has no video tiles.
