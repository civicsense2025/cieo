FollowButton

A filled Follow button that becomes an outlined Following, previewing Unfollow on hover or focus.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { followLabel, FollowButton } from 'cieo/FollowButton';
<FollowButton following={following} onToggle={toggle} name="Ava" />

Properties

NameTypeDefaultDescription
followingboolean—Whether the viewer follows now.
onToggle() => void—Called on every press.
namestring—Who is followed; added to the accessible name.
size'sm' | 'md'mdControl height.
classNamestring—Additional root CSS class. Built-in classes remain.
slotPropsobject—Typed presentation parts: root. Accepts className, style, title and non-reserved data attributes; owned semantics and dynamic styles remain.

Best practices

Pass the person name so the accessible name reads Follow Ava.
Don't hide the Unfollow preview; it keeps the destructive step from being a surprise.
