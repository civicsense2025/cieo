NumberedSteps

A short ordered process led by large numerals.

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { NumberedSteps } from 'cieo/NumberedSteps';
preset base · ω 22 rad/s · ζ 1.00 · settle 418 ms (1×) · 0.0% overshoot
  1. 1Say who you areName and ZIP code
  2. 2Name the bill
<NumberedSteps steps={[{ title: "Say who you are", detail: "Name and ZIP code" }, { title: "Name the bill" }]} />
npx cieo add NumberedSteps

Anatomy

Properties

NameTypeDefaultDescription
stepsobject[]—{ title: string; detail?: string }[]
classNamestring—Additional root CSS class. Built-in classes remain.
slotPropsobject—Typed presentation parts: root. Accepts className, style, title and non-reserved data attributes; owned semantics and dynamic styles remain.

Guide

Use when

  • How-to instructions in order, such as a call script.

Avoid when

  • Progress through a process; use StepList.

Anatomy

Root ol.cieo-p-numbered-steps.

Behavior

No motion.

Keyboard / accessibility

  • List order is announced; numerals are decorative.

Do / don't

  • Do: <NumberedSteps steps={[{ title: 'Say who you are' }]} />
  • Don't: Don't exceed six steps.
