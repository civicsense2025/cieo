AuthResetForm

Request step plus confirm step for reset.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { AuthResetForm } from 'cieo/AuthResetForm';
<AuthResetForm id="reset" step="request" onRequest={send} onConfirm={save} />

slotPropsobject—Typed presentation record; see TypeScript declaration. Named parts: root, submit.

Best practices

Do confirm the link was sent before switching steps.
Don't switch steps on a failed request.
