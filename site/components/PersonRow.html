Components/Molecule

PersonRow

A person beside their name and one detail line; compact is a roll-call entry.

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { PersonRow } from 'cieo/PersonRow';
Sen. CapitoR-W.Va. · Sponsor
<PersonRow name="Sen. Capito" detail="R-W.Va. · Sponsor" ring="#b42318" />

Properties

NameTypeDefaultDescription
namestring—Required.
detailstring—Optional.
srcstring—Optional.
ringstring—Optional.
compactbooleanfalseOptional.
grayscalebooleanfalseOptional.
classNamestring—Additional root CSS class. Built-in classes remain.
slotPropsobject—Typed presentation parts: root. Accepts className, style, title and non-reserved data attributes; owned semantics and dynamic styles remain.

Guide

Use when

  • Sponsors, members or authors are listed by name.

Avoid when

  • The row needs actions; wrap it in ListItem.

Anatomy

Root div.cieo-p-person-row: Portrait then name and detail.

Behavior

Names never wrap.

Keyboard / accessibility

  • The Portrait is hidden; the name speaks.

Do / don't

  • Do: <PersonRow name="Sen. Capito" detail="R-W.Va. · Sponsor" ring="var(--party-r)" />
  • Don't: Don't abbreviate titles inconsistently.
