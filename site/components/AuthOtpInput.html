AuthOtpInput

Digit boxes with paste normalization.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { AuthOtpInput } from 'cieo/AuthOtpInput';
<AuthOtpInput id="otp" onComplete={verify} />

Properties

NameTypeDefaultDescription
idstring—Binds the group label and error.
lengthnumber6Four to eight boxes.
errorstring—Error text.
disabledbooleanfalseDisabled state.
onCompletefunction—Fires once the last box fills.

Best practices

Do strip spaces and dashes on paste.
Don't accept non-digits into the boxes.
