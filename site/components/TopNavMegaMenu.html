TopNavMegaMenu

Controlled disclosure panel below a trigger (a "Products" menu with rich rows).

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { TopNavMegaMenu } from 'cieo/TopNavMegaMenu';
Web
<TopNavMegaMenu trigger="Products" defaultOpen><TopNavMegaMenuItem href="/web" title="Web" /></TopNavMegaMenu>

Properties

NameTypeDefaultDescription
openboolean—Controlled open state.
defaultOpenbooleanfalseUncontrolled initial state.
onOpenChangefunction—Open-state change handler.

Best practices

Use one trigger with rows and at most one featured card per panel.
Don't nest mega menus or place triggers where the panel overflows.
