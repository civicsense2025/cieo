AgentStatus

A dot plus words that name an agent's or run's reported state.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { AgentStatus, AGENT_STATUS_TONES, AGENT_STATUS_WORDS } from 'cieo/AgentStatus';
ResearcherWorking Needs you Failed
<AgentStatus status={agent.status} name={agent.name} />

Properties

NameTypeDefaultDescription
statusStatus—The status the host reported. Never a guess or an optimistic value.
labelstring—Words shown for the status. Overrides the default words; they must still name the state.
namestring—Agent or run name shown before the status, e.g. "Researcher". Optional.
classNamestring—Additional root CSS class. Built-in classes remain.
slotPropsobject—Typed presentation parts: root. Accepts className, style, title and non-reserved data attributes; owned semantics and dynamic styles remain.

Best practices

Do pass the status the host reported.
Don't pass a label that drops the state.
