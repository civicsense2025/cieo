MultiSelector

Label plus a native multi-select reusing the design-system input style.

Usage

<MultiSelector label="Committees" values={values} onChange={setValues}>
  <SelectorOption value="approp" label="Appropriations" />
  <SelectorOption value="rules" label="Rules" />
</MultiSelector>

Properties

NameTypeDefaultDescription
labelstring—Visible label naming the set.
valuesarray—Controlled selected values.
onChangefunction—Host change hook with the full selected set.

Best practices

Pair with SelectorOption children and short help text for multi keys.
Don't restyle the select; .cieo-input is the shared paint.
