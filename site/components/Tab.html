Tab

One tab inside a tab row, selected when the shared value matches.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { Tab } from 'cieo/Tab';
import { Tab } from 'cieo';
<TabList label="Settings sections" value={tab} onValueChange={setTab}>
  <Tab value="general">General</Tab>
  <Tab value="billing">Billing</Tab>
</TabList>

Properties

NameTypeDefaultDescription
valuestring—Tab key matched against the shared value.

Best practices

Keep tab text to one or two words so the row scans fast.
Do not render it outside a TabList or TabMenu; it carries no tab semantics there.
