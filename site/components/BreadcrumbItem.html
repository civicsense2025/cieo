Components · Atom

BreadcrumbItem

One crumb in a Breadcrumbs trail: a link, or the current page.

Usage

  1. Home
  2. Report
<Breadcrumbs>
  <BreadcrumbItem><a href="/">Home</a></BreadcrumbItem>
  <BreadcrumbItem current>Report</BreadcrumbItem>
</Breadcrumbs>

Properties

NameTypeDefaultDescription
currentbooleanfalseMarks the current page with aria-current.

Best practices

Use current for the last crumb with plain text, no link.
Don't wrap the current page in an anchor or set current on a linked crumb.
