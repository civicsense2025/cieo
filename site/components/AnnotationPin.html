AnnotationPin

A numbered teardrop marker whose tip sits on a point of a layer, for pin-and-comment review.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { annotationPinLabel, clampUnit, AnnotationPin } from 'cieo/AnnotationPin';
<AnnotationPin index={3} x={0.42} y={0.3} label="Ava" selected onSelect={open} />

Properties

NameTypeDefaultDescription
indexnumber—1-based number drawn on the pin and spoken in its name.
xnumber—Horizontal position, 0..1 of the layer.
ynumber—Vertical position, 0..1 of the layer.
state'draft' | 'open' | 'resolved'opendraft is unsent, open has a thread, resolved is muted and smaller.
selectedbooleanfalseDraws a ring while its thread is open.
labelstring—Author name added to the accessible name.
initialsstring—Characters drawn in place of the number.
onSelect() => void—Called when the pin is pressed.
classNamestring—Additional root CSS class. Built-in classes remain.
slotPropsobject—Typed presentation parts: root, body, text. Accepts className, style, title and non-reserved data attributes; owned semantics and dynamic styles remain.

Best practices

Give every pin its number from array order, so the thread list and the pins agree.
Don't hide the number behind an icon; the number is how reviewers refer to a comment.
