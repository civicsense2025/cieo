Components · Molecule

Field

Label plus one control plus a help or error row (every labelled input, select, or custom control).

Usage

Use your work email

<Field label="Email" htmlFor="email" description="Use your work email">
  <input id="email" type="email" />
</Field>

Properties

NameTypeDefaultDescription
labelstring—Visible label bound to the control.
htmlForstring—Id of the wrapped control for label focus.
descriptionstring—Help text shown when there is no error.
errorstring—Validation message; wins over description.

Best practices

Wrap every labelled control so label, input, and help text stay in one stack.
Don't render both description and error; pass error and let it win.
