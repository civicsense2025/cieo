DropdownMenuDivider

Visual split between menu clusters, for separating actions from danger rows.

Usage

import { DropdownMenuDivider } from 'cieo';
<DropdownMenuItem label="Duplicate" onSelect={duplicate} />
<DropdownMenuDivider />
<DropdownMenuItem label="Delete" onSelect={remove} />

Properties

NameTypeDefaultDescription

Best practices

Place one divider between clusters, never at the menu edges.
Do not use it as spacing between related rows.
