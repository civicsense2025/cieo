PowerSearch

Full search box under its Astryx name: a thin contract over the SearchField control.

Usage

import { PowerSearch } from '../../primitives/PowerSearch/PowerSearch.js';

<PowerSearch label="Search reports" onSearch={runSearch} />

Properties

NameTypeDefaultDescription
labelstring—Accessible name of the search box.
showLabelbooleanfalseShow the label visually instead of hiding it.
onSearch(value: string) => void—Called with the value on Enter.
onClear() => void—Called when the field is cleared.
collapsiblebooleanfalseStart as an icon button that expands into the field.

Best practices

Import PowerSearch wherever Astryx names the search box.
Don't fork search behavior here; change the SearchField control instead.
