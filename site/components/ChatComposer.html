ChatComposer

Controlled form shell for composing and sending a message (input plus a Send button).

Usage

<ChatComposer label="Send a message" onSubmit={send}>
  <ChatComposerInput label="Message support" value={draft} onChange={setDraft} />
  <button type="submit">Send</button>
</ChatComposer>

Properties

NameTypeDefaultDescription
labelstringSend a messageAccessible name for the composer form.
onSubmitfunction—Called after submit is intercepted. Host sends and clears.

Best practices

Send through the form submit so Enter and the button behave the same.
Don't add a second click-send path that bypasses submit.
