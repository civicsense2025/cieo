Selector

Thin contract over the Select control; reuses select styling.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { Selector } from 'cieo/Selector';
<Selector label="Chamber" options={["House", "Senate"]} value={chamber} onValueChange={setChamber} />

Properties

NameTypeDefaultDescription
labelstring—Visible label naming the select and combobox.
hideLabelbooleanfalseKeeps the label for assistive tech but hides it visually.
optionsarray—Options as SelectOption records or plain strings.
namestring—Native select name for form submit.
idstring—Native select id override.
valuestring—Controlled value.
defaultValuestring—Uncontrolled initial value.
onValueChangefunction—Host pick hook.
autoSubmitbooleanfalseSubmits the owning form after each pick.
formstring—Associates the select with a form elsewhere on the page.
disabledbooleanfalseDisables the control.
requiredbooleanfalseMarks the field required.
sizeenummdControl size, sm or md.
descriptionstring—Help text under the control.
classNamestring—Extra class hook.
