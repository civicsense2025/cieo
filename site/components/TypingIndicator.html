TypingIndicator

Three waving dots and a spoken sentence about who is typing, entering and leaving with a short fade.

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { typingLabel, typingSetKey, TypingIndicator } from 'cieo/TypingIndicator';
Ava and Ben are typing Ava is typing
<TypingIndicator names={["Ava", "Ben"]} />
typingLabel(["Ava", "Ben", "Cy", "Di"]) // "Ava and 3 others are typing"

Properties

NameTypeDefaultDescription
namesstring[]—Who is typing right now. An empty list hides the indicator.
variant'bubble' | 'inline'bubblebubble: dots in a bubble, sentence read aloud only. inline: dots with the sentence shown beside them.
classNamestring—Additional root CSS class. Built-in classes remain.
slotPropsobject—Typed presentation parts: root, body, dots, dot, text. Accepts className, style, title and non-reserved data attributes; owned semantics and dynamic styles remain.

Guide

Use when

  • A conversation shows that someone is composing a reply.
  • A list row wants a quiet inline hint in place of its preview.

Avoid when

  • Showing that something is loading; use a progress or skeleton pattern.

Anatomy

A role="status" span holding three decorative dots and the sentence. bubble shows only the dots in a rounded bubble; inline shows the sentence beside them.

Behavior

  • typingLabel(names) words one name, two, three, or four and more ("Ava and 3 others are typing"). Blank names are ignored.
  • The dots wave in a staggered, gentle loop. Reduced motion shows static dots at mid opacity.
  • An empty names list fades the indicator out; the status element stays so a later arrival is announced.
  • The spoken sentence changes only when the set of people changes, not when their order does.

Keyboard / accessibility

The status is a polite live region. Dots are hidden from assistive tech; the sentence is read.

Do / don't

  • Do: pass every typing name in one list.
  • Don't: debounce inside the component; the host decides when someone stops typing.

Customization

Use the typed presentation parts listed under Host customization. Defaults still use Cieo tokens; component behavior and accessibility remain owned by Cieo.

Limitations

  • Names are not truncated; very long names wrap in the bubble variant.

Related

ChatMessageBubble, ConversationListItem, DeliveryStatus.

Host customization

className adds a root class without replacing Cieo’s classes. slotProps exposes root, body, dots, dot, text. Each part accepts className, style, title, and non-reserved data-* attributes. Roles, accessible names, values, event handlers, refs, state markers, and dynamic geometry remain component-owned. Existing content props retain their original semantics.

Best practices

Pass the live list of names; the sentence only changes when the set of people changes, so screen readers are not spammed.
Don't render one indicator per person; pass them all and let it phrase the sentence.
