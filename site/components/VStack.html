VStack

Vertical stack under the HStack/VStack naming (card bodies, field columns).

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { VStack } from 'cieo/VStack';

House Bill 42

Passed committee 8–3; floor vote Thursday.

<VStack>
  <h3>House Bill 42</h3>
  <p>Passed committee 8–3; floor vote Thursday.</p>
</VStack>

Properties

NameTypeDefaultDescription
gapsm | md | lgmdGap between children. Same contract as Stack.

Guide

Use when

  • Children stack in one column with a single shared gap.
  • You want the HStack/VStack pair to read symmetrically in code.

Avoid when

  • Children flow in a row; use HStack instead.
  • The layout needs columns; use Grid with GridSpan instead.

Anatomy

Re-export of the shipped Stack (Stack as VStack, StackProps as VStackProps); same root, same data-gap. No new CSS ships with this primitive.

Behavior

No motion. Identical to Stack: gap defaults to md. Never steals focus.

Keyboard / accessibility

  • Presentational column only; no label, no landmark, no focus.
  • Children keep document order; identical to Stack semantics.

Do / don't

  • Do: <VStack> where the HStack/VStack pair reads best.
  • Don't: mix VStack and Stack for the same pattern in one file; pick one name.

Customization

This alias retains the owning control’s customization API; see Host customization below.

Limitations

  • Same limits as Stack: one column, one gap, no per-child alignment (see StackItem).
  • Wraps src/primitives/Stack/Stack.tsx; behavior changes there apply here.

Related

HStack (atom), Stack (molecule), StackItem (atom).

Host customization

Alias of Stack; preserves its native/owning component props instead of creating a second control contract. Use the underlying component’s supported className, style/native props, and content slots. This alias intentionally does not fork behavior or introduce a competing slotProps shape.

Best practices

Use VStack where the HStack/VStack pair reads best in code.
Don't mix VStack and Stack for the same pattern in one file.
