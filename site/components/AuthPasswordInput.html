AuthPasswordInput

Password input with strength meter and show-hide.

Usage

Use the import, not the markup. Copy this line into your code — never paste the preview HTML below.

import { AuthPasswordInput } from 'cieo/AuthPasswordInput';
<AuthPasswordInput id="pw" showStrength onChange={setPw} />
