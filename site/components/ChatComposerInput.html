ChatComposerInput

Controlled textarea for composing a message inside a composer (a reply to support).

Usage

<ChatComposerInput label="Message support" value={draft} onChange={setDraft} placeholder="Write a reply…" />

Properties

NameTypeDefaultDescription
labelstring—Accessible name for the input. Required.
valuestring—Current text. Host-controlled.
onChangefunction—Called on each edit. Host updates value.
rowsnumber1Visible row count.
placeholderstring—Placeholder hint.

Best practices

Keep the input controlled so the composer can clear the draft on send.
Don't reuse the composer's name on the input; give it its own label.
