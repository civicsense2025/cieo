Components · atom

DropdownMenuGroup

Labeled section that clusters related rows inside a dropdown menu.

Usage

Export
import { DropdownMenuGroup } from 'cieo';
<DropdownMenuGroup label="Export">
  <DropdownMenuItem label="Export PDF" onSelect={exportPdf} />
  <DropdownMenuItem label="Export CSV" onSelect={exportCsv} />
</DropdownMenuGroup>

Properties

NameTypeDefaultDescription
labelstring—Section name announced with the group.

Best practices

Cluster rows that share one verb so the caption earns its place.
Do not wrap a single row; a group of one announces noise.
