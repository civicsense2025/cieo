CompactCount

A count shortened for scanning (26.3K) whose digits roll in the direction of change, with the exact number kept for screen readers.

Usage

Use the import, not the markup. Copy this line into your code; never paste the preview HTML below.

import { formatCompactCount, formatExactCount, CompactCount } from 'cieo/CompactCount';
26.3K26,300 views
<CompactCount value={26300} unit="views" />
formatCompactCount(1640) // "1.6K"

Properties

NameTypeDefaultDescription
valuenumber—The count to show.
localestringenLocale for formatting.
unitstring—Word read after the exact number, such as likes or views.
hideZerobooleantrueZero renders nothing visible, as feeds do. False shows 0.
motionbooleantrueFalse swaps the number without rolling.

Guide

Use when

  • Showing likes, replies, reposts, views or members next to an action.
  • The number changes while someone watches it, and the direction of change matters.

Avoid when

  • The exact figure is the point (a ballot tally, an invoice); use plain text.

Anatomy

A span with a visible short form (aria-hidden) and a visually hidden exact form ("26,300 views").

Behavior

  • formatCompactCount(n) uses Intl.NumberFormat compact notation with one decimal: 164, 1.6K, 26.3K, 4M.
  • Negative, fractional and non-finite input clamps to a whole count of at least 0.
  • Zero hides the visible number by default, as feeds do; hideZero={false} shows it.
  • Changes roll only the digits that changed (shared Digits). Reduced motion swaps instantly.

Keyboard / accessibility

Not focusable. The hidden exact form is what screen readers announce.

Do / don't

  • Do: pass a unit so the spoken form makes sense on its own.
  • Don't: pre-format the value into a string.

Customization

Use the typed presentation parts listed under Host customization. Defaults still use Cieo tokens; component behavior and accessibility remain owned by Cieo.

Limitations

  • One decimal place. Locales without compact notation fall back to the full number.

Related

CountButton, AudioTime, Badge.

Host customization

className adds a root class without replacing Cieo’s classes. slotProps exposes root. Each part accepts className, style, title, and non-reserved data-* attributes. Roles, accessible names, values, event handlers, refs, state markers, and dynamic geometry remain component-owned. Existing content props retain their original semantics.

Best practices

Pass the exact count and a unit; the short form is for the eye, the exact form for assistive tech.
Don't pre-format the number into a string; the roll needs the real value to pick its direction.
