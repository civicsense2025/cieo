Three ideas

Less to tune, more to trust.

One spring, no tuning

Every motion is a closed-form critically damped spring set by one number, its natural frequency. It cannot overshoot, so there is no bounce to tune away.

The same on web and Apple

DOM and React on the web, SwiftUI on Apple platforms. The same presets, so a screen feels the same wherever it runs.

Themed by tokens

7 brands, 5 corner profiles, 3 densities and 3 grounds. Every combination of color is audited for contrast before it ships.

The library

Foundations first, then use cases.

Primitives are the foundation. Atoms, molecules and organisms build on them. Packs gather the parts that only make sense for one kind of product, so you never see sign-in cards while building a docs site.
