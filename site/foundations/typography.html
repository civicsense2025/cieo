Foundations/Type and shape

One typeface, calm shapes.

Cieo uses a single clean sans typeface for headings, body text and buttons, so a screen reads in one voice. It is the font already on the person's device, so there is nothing to download and no text jumping around while a font loads. Corner style and spacing change the personality of an app without touching how easy it is to tap.

How to use it. Use the size names (--cieo-text-heading, --cieo-text-body) instead of pixel values, and the weight names for emphasis. Headings use the same font as the rest of the page. If your brand needs a different feel, choose font: 'humanist' or 'mono' in the theme and every heading and label follows.

Corners and spacing

Try the five corner styles and three densities. Dense layouts fit more on screen, spacious ones are easier on thumbs. Buttons and fields never get smaller than a comfortable touch target in any of them.

How to use it. Corners and density are two options on the theme. Everything that uses the theme updates together, so you never restyle buttons one by one.
