Foundations/Springs that settle

Motion that glides to a stop.

When someone taps a button or drags a sheet, it should move like a real object: it speeds up, glides, and comes to rest. Cieo does this with springs, which are motion that eases to rest on its own instead of following a fixed animation clip. Nothing wobbles or gets cut short, the most a spring may overshoot is about 5%, and if the person changes their mind halfway the motion carries on smoothly from where it is.

Try a spring

Press Move it to send the dot across. Pick how quickly it should arrive, and how much bounce it is allowed. Cieo keeps bounce small on purpose: at most about 5% past the target, usually none.

Cieo spring A bouncy spring, which Cieo does not use

Settles in 418 ms. It never goes past its target.

How to use it. You rarely write spring math yourself. Components already move on a spring, and you choose a feel by name: snap for small feedback like a press, base for most things, soft for big panels, lazy for slow reveals. To move your own element, hand a target number to useSpring and draw each frame it gives back.

import { useSpring } from 'cieo/react';

useSpring(open ? 0 : 320, (y) => {
  sheet.current.style.transform = 'translateY(' + y + 'px)';
}, { preset: 'soft' });

Dragging, pulling past the edge, and letting go

A sheet follows your finger exactly while you drag. Pull it past its limit and it gets harder and harder to move, like stretching a rubber band. Let go and it snaps to the nearest resting place, and a quick flick carries it to the next one.

The sheet settles on the 50% stop. You pulled 80 px past the edge, but it only moved 49 px.

How to use it. Two small helpers do the work during a drag. rubberBand turns how far past the edge the pointer went into how far the sheet moves, and projectToDetent picks the resting place from the release position and flick speed.

import { rubberBand, projectToDetent } from 'cieo/live';

const shown = rubberBand(pulledPastEdge, sheetHeight, 0.55);
const restAt = projectToDetent(position, velocity, [0, 0.5, 0.9]);
