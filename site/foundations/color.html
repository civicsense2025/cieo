Foundations/Color that stays readable

Any brand color, still easy to read.

A color that looks great in a logo can make small text hard to read, especially for people with low vision or in bright sunlight. Cieo builds every text, background, button and status color from your brand color so the contrast, meaning how clearly text stands out from what is behind it, stays high. It is checked in 168 combinations of brand, light/dark and contrast before each release.

How to use it. Pick a brand, a background, and whether it is light or dark, then apply the theme to any part of the page. Behind the scenes the colors are built in OKLCH, a color model where equal steps look equally different to the eye, which is why one brand color can produce a full, readable set. If a combination would fail a check, createTheme refuses it and tells you which pair, so unreadable text cannot ship by accident.

import { createTheme, applyTheme } from 'cieo/design';

applyTheme(document.body, createTheme({
  brand: 'lagoon', ground: 'paper', scheme: 'dark', contrast: 'high',
}));
